# 章节金字塔 — 追影

> 状态修订：17。按需取层：审第N章 = 卷摘要 + 近10章章摘要 + 本章全文。

## 章摘要（全量）

| 章 | 摘要 |
|---|---|
| 1 | 倒叙钩子：四十七岁那年在早点铺，他开口说了半句就被打断，那是他最后一次开口（归第二世）。落回九岁开学第一天：放学看李婶家孩子的手，说“他是要抽”，没人信；当夜真抽，次日医生的话与他一字不差。隔门听见舅舅踩老爸，他进屋把老爸那杯酒倒回瓶里、换上一杯水，杯把手朝外。回头看见老爸眼白发黄、指头抖着，他什么都没说。 |
| 2 | 他记得院门口有棵槐树，老妈说没有。早点摊小满妈问“吃饭了没”，小满把最热的包子递给他；他顺口说“碱放早了”就走。中午张家那辆车丢了，锁是好的。教室里合影角落糊着一团白。放学递扳手，看见老爸指甲盖发白、站起来扶墙。饭前他把瓶里的酒倒空、灌上凉白开放回原处；晚饭老爸喝到那杯“酒”愣住。那半杯没人动，他倒进院子。 |
| 3 | 舅舅上门踩老爸，一句“你这辈子也就这样了”点着了他。他连问三句：厂子在东郊吧、上月的货是不是压着、你押在里头的钱是借的吧——把三十万逼出来。舅舅当场去院里打电话求证，回来手抖烟掉，酒没喝就走，留下一瓶。他把功劳推给老爸：“我听我爸说的。”老爸全程没说话，第一次正眼看他。 |
| 4 | 三次试探全被当小孩糊弄。学校发健康表，他多拿了一份压在课本底下，另一份放在老爸手边，什么都没说。老爸翻到家族史那一栏停住，问起自己父亲走的时候是啥毛病，老妈说是肝。老爸说：我也该去查查。 |
| 5 | 他跟陈默进网吧，那孩子面前不是游戏，是一屏黑底白字，卡了三天。他看了两分钟，改三行，跑通。陈默问怎么会的，他说不知道；问改哪儿，他已经忘了。他立规矩：周三你去，周六我教你，别问从哪儿学的。回家时院里公用水龙头裂了，水漫了半个院子。 |
| 6 | 陪老爸拿体检结果。医生说了三个词他一个没听懂。单子上有个箭头朝上，他看了三遍才明白朝上是坏。回家路上老爸买了两根冰棍，他把少喝酒说到底。第二天小满替人顶错，被他当场否掉。他把化验单折成三折塞进课本。 |
| 7 | 刘虎在砖厂后头收过路费。他放下书包，脱了外套叠成方块压在上面，侧半步搭肘一带，刘虎自己撞上砖垛；第二次扣手腕下压，刘虎跪了，不到十秒。他抬起脚又放下，没踢。走后墙根一只鞋，台阶上一只鞋。 |
| 8 | 那小孩在校门口等他，说你打架像我哥。问哥哥在哪儿，答不知道，走了。刘虎没来收钱，说是自己摔的。放学那小孩塞给他一块用剩的橡皮，说欠人的要还。他收了。橡皮上有个牙印，不是他的。 |
