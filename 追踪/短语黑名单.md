# 短语黑名单（本书 tic 词表，项目填）

> 短语级 tic 的频次管理（advisory）：章检跑 `guyin-check-ai-patterns.js` 时按本表限额计数，超限报 advisory——是提示不是拦截，改写还是保留由五测试判。
> 框架不预置词表：每本书的 tic 不同（复盘报告 A4 的「记下/贴着腕骨/凉而/看进眼里」是《白银案录》的 tic，属项目内容不属框架）。
> 兼任工艺词登记位（W3）：本书的题材工艺词（「社会脸」类分析词，应在细纲层括注翻译、漏进正文的）也登记在此，命中即报。

| 短语 | 限额 |
|------|------|
| **手**（作场景第一笔的落点，如"他低头看自己的手"） | 每章 ≤2，**相邻章禁用**（B7：相邻章不共用同一身体锚点） |
| **他没说话 / 他没接话 / 谁都没说话** | 每章 ≤2，近 5 章 ≤6 |
| **看了他一眼 / 看了很久 / 看了一眼** | 每章 ≤2 |
| **凉 / 烫**（温度词，亲密场景高频） | 每章 ≤3 |
| **"嗯。"**（单独成句） | 每章 ≤4 |
| **想了想 / 想不起来**（失忆症相关，易复读） | 每章 ≤2 |
| **手上 / 手里**（镜头落手的衍生） | 每章 ≤3 |

> **v10 登记**。本表针对本书的**纪律性 tic**——不是一般的口水词，
> 而是"三不写 + 镜头落手 + 对话极短"这三条纪律**必然催生**的复读。
> 例：因为不写心理活动，写手会不自觉地反复用"他没说话"来替代沉默描写；
> 因为镜头一律落手，"手"字会失控。**登记后让脚本数数，不靠感觉。**

### 兼任工艺词（W3，命中即报）

> 本书的题材工艺词＝**不该出现在非专业场景的术语**。漏进正文即报 advisory。

| 工艺词类别 | 举例 | 判定 |
|---|---|---|
| **中医术语** | 肝气郁结、热极生风、经络、望闻问切、君臣佐使 | 出现在**小孩/非专业场景**即报；专业场景（他成年后与同行对话）允许 |
| **金融术语** | 仓位、止损、杠杆、K 线、对冲、做空 | 同上。**卷一（9 岁）全禁** |

## 登记纪律

- **何时登记**：章检 advisory 反复报同一短语、复盘报告点名的 tic、「这词好像又用多了」的直觉——登记后让脚本数数，不靠感觉；
- **限额三档**：每章 ≤N（高频动作/感受 tic）／近 5 章 ≤N（跨章复读 tic）／相邻章禁用（身体锚点、收束句连用——B7「相邻章不共用同一身体锚点」的事故形态）；
- **作者性语句不登记在此**：气句/一生之问/私人切口是 H2 blocking 管的泄漏，不是 tic——两级不混（docs/06 §1.5）；
- **短篇项目**：模板不预置本文件；手工在项目根建 `追踪/短语黑名单.md` 同格式即生效（窗口档按整篇计、相邻档不判）；
- **每卷末复核**：连续 2 卷零命中的条目退役（tic 已戒），新 tic 随卷追加。
