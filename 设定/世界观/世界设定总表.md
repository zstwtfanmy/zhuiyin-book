## 三、中医规则（他的第二样本事）

| 项 | 规则 |
|---|---|
| **说话必须土** | 望诊的话一律用土话："他是要抽。""手指头直着，不会弯。"**禁用一切术语**（热极生风、肝气郁结、经络） |
| **他看得见，说不出原理** | 他能判断，但讲不出为什么（v9 脑洞③失忆症）。**这是设定，不是谦虚** |
| **他不开方**（卷一） | 9 岁开方会暴露。卷一只做两件事：**看出来**、**推去体检** |
| **他能治，但不能根治"不想好的人"** | 呼应主题：病能医，人不能医 |
| **药与病是主比喻域** | 他看世界一律用药与病的眼光（"这人虚""这事得慢慢调"） |

## 四、金融规则（可操作边界 —— 这是障碍，不是外挂）

> **核心**：预知不是外挂，**年龄才是最大的敌人**。卷二"一次大爽拆四步"就靠这四道墙。

| 时期 | 他能做什么 | **他不能做什么（障碍）** |
|---|---|---|
| 2000（9 岁） | 建议老爸、算小账、摆小摊 | **不能开户、不能签合同、不能注册公司、钱要过爸妈的手** |
| 2002-05 | 用家人的名义、做小生意 | 大额资金要家长签字；被当小孩（ch042 被康九坑就是因为合同不是纸上写的算） |
| 2007（15 岁） | 出主意 | **仍不能开户**（需满 18）——6124 那波只能借别人的手 |
| 2008（18 岁） | 第一次真正自己操作 | 本金有限；第一次遇到"算不准的人"（姜淮） |
| 2014+ | 全都能做 | 但**开始遇到"不能碰的钱"**（暗线·灰层） |

> **纪律**：每次"他不能直接做"的时候，**不许用金手指绕过**——必须写实打实的绕路（借名、合伙、托人）。
> 绕路过程本身就是爽点（读者爱看"聪明人怎么绕过规则"）。

## 六、禁忌清单（生成正文前必查）

### 6.1 禁用词（出现即错）

| 类别 | 词 |
|---|---|
| **机制类** | 重生 / 穿越 / 前世 / 系统 / 金手指 / 轮回 |
| **情绪类** | 五味杂陈 / 百感交集 / 心中一紧 / 莫名 / 一丝 / 不禁 |
| **网络用语** | 一切流行语（"你咋不上天"类） |
| **术语** | 中医术语、金融术语（**在小孩/非专业场景**） |

### 6.2 三不写

1. **不写心理活动**（内心活动一律外化：动作、物的状态、说的话）
2. **不写"他想起了第 X 世"**（前两世只是背景）
3. **不写拥抱**（偏执点 B；最亲密的表达永远是递东西）

### 6.3 不可做的事

| # | 禁令 |
|---|---|
| 1 | **主角不炫技**——他从不解释自己怎么知道的，被问就说"看的" |
| 2 | **主角不搞笑**——笑点由别人制造（李婶、王浩、老妈、舅舅） |
| 3 | **禁止她（小满）有任何"意味深长"的表情或台词**（v4 硬纪律） |
| 4 | **禁止任何人点破两条暗线**（记忆偏移、代价账本）——直到 ch131 |
| 5 | **禁止"她不入镜"被解释成灵异**——每次现场必有人给一个最土的解释（"这相机不行"） |
| 6 | **章尾末句必须是名词或动作**，不许是感慨，禁用省略号 |

## 七、他的能力边界（一句话记住）

> **他会做，写不出步骤。**
> **他记得每一个失去的瞬间，记不住任何一条能抄的作业。**

| 他行 | 他不行 |
|---|---|
| 望诊（看得准，说不出原理） | 抄作业（记不清哪天、哪一家） |
| 判断人（看手、看脸色） | 判断"她要不要留下"（全书核心矛盾） |
| 改事情（病、钱、行情） | 改**人自愿做的选择**（锚点） |
| 在床上无所不能 | 在感情上一句话都说不出来 |

> **这一条既是设定，也是主题**：他的全部能力都在身体上，而这本书讲的是**身体解决不了的事**。
