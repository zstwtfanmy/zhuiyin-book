# 温若（角色卡 · v11）

> **ch031 出场。全书第二重要的女性，也是唯一一个"被他辜负"的人。**
> 她是周晚的镜像：**周晚等他开口，他没说；温若等他回头，他没回。**
> **小满是"求不得"，温若是"已拥有却没珍惜"**——前者是命运的痛，后者是**自己的痛**。

## 二、核心：她要什么，为什么走

| 项 | 内容 |
|---|---|
| **她要什么** | **要他回头看她一眼。** 不是要他爱她，是要他**看见她在** |
| **她为什么不逼** | 她太了解他了。**逼一次，他就退一次。** 所以她选择等 |
| **她为什么走** | 不是攒够失望。**是她终于确认：他回头的时候，看的不是她** |
| **她的自我认知差** | 她坚信"再等等他就回头了"；事实是——**他回了头，看的不是她** |
| **她的知识边界** | 知道他心里有别人；**不知道那个人是谁，更不知道那个人根本没选他** |

> ⚠ **这一条是全书最大的反讽**：她以为自己在和一个"忘不掉前任的男人"竞争。
> 而真相是——**那个"前任"从来就没选过他。她在和一个不存在的人竞争。**

---

## 三、对话签名（照 `语言纪律.md` 第四节卡）

| 项 | 内容 |
|---|---|
| **一句话上限** | **无上限（全书唯一说完整长句的人）** |
| 句式 | 复句。会**替他把话收尾** |
| 问号 | **会问**（全书会问的只有：程守拙、顾延龄、姜淮、温若） |
| 她是他唯一说不过的人 | 不是因为她会吵，是因为**她说的都对，而且说完就停** |

### 三条从签名长出来的硬纪律

1. **她是唯一把话说出口的人 → 所以她是唯一没被听见的人（ch100-101）。**
2. **她的长句在后期要变短**——等到她决定走的时候，她说的话比他还少。
   → **一个说完整句子的人开始说短句，就是她要走了。** ch173-180 检查这一条。
3. **她从不说"你为什么不看我"。** 全书一次都不说。

## 四、签名动作（写她只用这三个）

| # | 动作 | 出现密度 |
|---|---|---|
| 1 | **替他把话收尾**——他说半句，她接下去，接得比他想说的更准 | 全书高频，每卷 ≥2 次 |
| 2 | **把手边的东西挪一挪**（杯子、文件、椅子）——她在场时永远是她在收拾 | 中频 |
| 3 | **她站的位置永远在他半步之后、半步之侧** | 低频但关键，ch180 一次性回收 |

> **第 3 条的用法**：全书不点破。ch180 她走的那天，**她第一次站到了他前面**——
> 因为那天是她先转身。**读者回头才发现她一辈子都在他侧后方。**

## 七、八条铁律（写她不许破）

| # | 铁律 |
|---|---|
| 1 | **任何情况下不逼他表态** |
| 2 | **他忙的时候不添乱** |
| 3 | **退出时不吵、不质问、不哭**（她这辈子最多红一次眼眶，且不许在他在场的时候） |
| 4 | **她从不说"你为什么不爱我"**——同类句子全书禁用 |
| 5 | **她不傻。** 她什么都看得明白，只是选择不说 |
| 6 | **她不是工具人、不是等男主的容器。** 她有她的事业线（她是合伙人，不是秘书） |
| 7 | **她走之后不许回来**（除了 ch197-200 的请柬）。**走了就是走了** |
| 8 | **她的退出必须是体面的**——体面的退出比撕心裂肺更难写，也更疼 |

## 九、与主题的接口（最重要的一节）

> **他是小满。**
>
> 前半本书：他追小满，小满追别人。
> 后半本书：温若追他，他追小满。
> **他完整地站进了当年小满站过的那个位置。**

所以 ch180 那句"别送"是**全书主题唯一一次可见的动作证据**：

- 他在小满身上学会的东西，**用在了温若身上**；
- 他没能对小满做到的事（不去、不追、不打扰），**他对温若做到了**；
- **这是"释怀"的唯一证据。不是想通了，是做出来了。**

> 也是六次"自愿选择"里**唯一一次他听懂的一次**：
> 乔蔓"我要当最后一个"／池遥"我不要名分"／周晚"我要走"／岑玫"不要一个心里有人的"／温若"别送"/ 小满"郑川"。
> **他用了六段关系，才学会一件事——别人的选择不是冲着他来的，那只是她们的日子。**
