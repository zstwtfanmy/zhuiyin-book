# 核心四人 · 正式卡（v11）

> **本文件把 `_骨架_余五人.md` 中的周晚 / 赵铁柱 / 苏老，以及 `对手体系.md` 中的顾延龄，从骨架升为正式卡。**
> 骨架只锁"不能动的东西"；本文件补齐**签名动作、章位、身体线、与主题的接口、禁止提前释放**——这五项是生成正文时天天要查的。
>
> **四人共同点**：**他们都不是"配角"，是主角三级递进的四级台阶。**
> 周晚（时机）→ 铁柱（人）→ 苏老（心）→ 顾延龄（他自己）。

## 一、周晚（第一世 · 势均力敌的错过）

### 基本盘

| 项 | 内容 |
|---|---|
| 身份 | 第一世金融同行。**跟他一个层级，看得懂他每一步** |
| 世代 | **第一世（背景）**。本世重逢于卷三 |
| 章位 | **ch089-098**（10 章）。出场晚，退场快 |
| 身体层级 | **发生过一次**。两人都知道没有明天（见 `大纲/亲密关系谱系.md`） |
| 她的选择 | **`"我要走。"`**——**方式不同，日期相同（F5）** |

### 核心

> **她不是被抢走的，是她自己走的，而他没开口留。**

- **三级递进·第一级「时机」**：他以为改的是时机，结果连时机都没改动。
- **本世重来结果**：**他开口了，她还是走。**
  → 这是三级递进里最"轻"的一级，必须最轻——**后面还有两级更重的**。

### 签名（写她只用这些）

| 项 | 内容 |
|---|---|
| **对话** | 中长句。**专业词当日常**（"这个仓位""止损""平掉"）。跟他说话像开会 |
| **签名动作** | **她看表。** 不是不耐烦，是她这辈子只信时间 |
| **她的手** | 指甲剪得很短，指节明显。**常年写字的人的手** |
| **问号** | 少。她不问"你爱不爱我"——**她只问"这个仓位你怎么看"** |

### 三条铁律

1. **不等人**（她的信条，也是她最后走的原因）
2. **走之前不留联系方式**
3. **任何情况下不说"你为什么不留我"**

### 章位表

| 章 | 内容 |
|---|---|
| 089 | 重逢。她在会议室那头，他一眼认出来 |
| 091-093 | 同行交手。**她是全书第二个"看得懂他"的人**（第一个是姜淮） |
| 094-096 | **那一次**（身体线·一夜）。**两人都知道没明天** |
| 097 | 他开口了。**他这辈子第一次开口留人** |
| **098** | **她还是走了。F5：日期与他记忆里的那一天，一天不差** |

### 回响句

> **`"原来不是我没说，是我说了也没用。"`**

- 这句话在 **ch131** 才由他自己想起来（不是别人说的）。
- **它与 ch101 温若的"差点说破"构成对仗**：他对周晚开口了没用，温若对他开口了没被听见。

### 禁止提前释放

- ch097 之前**不许写他有任何留人的念头**
- **F5 日期**在 ch098 之前不许明示
- 他为什么知道她会走（**这是"时机不可移"，ch131 才点**）

## 二、赵铁柱（第二世 · 改三次还是死）

### 基本盘

| 项 | 内容 |
|---|---|
| 身份 | 第二世战友。话多，爱摆弄电子设备，**叫他"舟子"** |
| 世代 | **第二世（背景）**。本世重逢于卷四 |
| 章位 | **ch103-114**（12 章）。**ch114 死** |
| 身体层级 | 无（兄弟，不是情人） |
| 功能 | **终极遗憾的第一次完整预演**——读者在这里学会"主角改了也可能没用" |

### 核心：三次改动

| 次 | 他改了什么 | 结果 |
|---|---|---|
| 1 | 改路线 | **死在路线上** |
| 2 | 改时间 | **死在等待里** |
| 3 | 把他调离 | **他自己跑回来** |

> **第三次的关键**：他跑回来是因为他知道了——**他不能让沈亦舟一个人去。**
> **锚点机制第一次显形：不是命运的问题，是人心的问题。**

### 签名（写他只用这些）

| 项 | 内容 |
|---|---|
| **对话** | **废话多。正经话一句没有。** 口头禅"得嘞" |
| **签名动作** | **摆弄电子设备**（拆了装、装了拆）。**他到死手上都有个拆了一半的东西** |
| **他的手** | 粗糙，虎口有茧，指甲缝里是黑的 |
| **问号** | 少。**他从不问为什么** |

### 三条铁律

1. **任何情况下不让他一个人去**（这不是忠诚，是他自己的信条）
2. **不说煽情的话**——临死说的都是废话（"得嘞""我这玩意儿还没装完"）
3. **从不怪他**（这是最狠的一条）

### 章位表

| 章 | 内容 |
|---|---|
| 103-104 | 重逢。他还是老样子，还是"得嘞" |
| 105-107 | 他发现不对（老猫那条线） |
| **108** | **他为铁柱大打出手**（隐杀式爽点第 5 次暴起）。**没用** |
| 109-110 | **第一次改动**（改路线） |
| 111 | **第二次改动**（改时间） |
| 112 | **第三次改动**（调离他） |
| **113** | **他自己跑回来了** |
| **114** | **铁柱死。** 偏执点 A：他一个人吃了七天的席面剩菜 |

### 回响句

> **`"你改得了路，改不了人。"`**

- 这句话由铁柱在 **ch111** 前后随口说出（他自己不知道这话有多重）。
- **ch131 它自己回来**——不许由任何角色重提。

### 禁止提前释放

- ch113 之前**不许点破"他是自己回来的"**
- **老猫（内鬼）不许被写成纯粹的恶**——他就是一个做了选择的人
- 铁柱死前**不许有任何"托付"的戏**（他到死说的都是废话）

## 三、苏老（第三世 · 他不在场）

### 基本盘

| 项 | 内容 |
|---|---|
| 身份 | 第二世中医师父。教他医术，也教他"怎么面对治不好的人"——**后者他没学会** |
| **本世身份（v8 定案 B）** | **本世他没拜师。** 苏老是"同行前辈"，ch163 才真正走近<br>**→ 他一辈子叫他"苏老"，没叫过师父** |
| 章位 | **ch163-172**（卷五）。**ch172 死。此后全书不许再死人** |
| 身体层级 | 无 |
| 功能 | **不是没能力救，是不在。** 把无力感从"命运"转到"他自己身上" |

> **本世为什么不拜师（三条理由，写入纪律）**：
> ① 更克制，也更疼；② 符合"体面赢"的调性；③ **不提前泄漏**（方案 C 会提前点题）。

### 核心

> **他去救一个能救的人，没赶上送师父。**

- 这一条为论道那句最狠的话铺路：
  **"你不是想救她。你是不肯承认有人替你死过。"**（ch122）

### 签名（写他只用这些）

| 项 | 内容 |
|---|---|
| **对话** | 慢。**句子长。爱用农活比喻**（"这病得像拔草，得连根，不能揪叶"） |
| **签名动作** | **手抖**——他老了，撮药的时候手抖，但**一钱不差** |
| **问号** | 少 |
| 遗物 | **一页手稿。不是医方，是一句话**（F6，卷五论道的钥匙） |

### 三条铁律

1. **不收徒弟的钱**
2. **治不好就说实话，不许安慰**
3. **不许徒弟守在床边**（耽误出诊）——**这条是他自己死时没人送的原因**

### 章位表

| 章 | 内容 |
|---|---|
| 163-165 | 走近。他已经很老了，还在看诊 |
| 166-168 | 他生病。**主角明明看得出来，却没有停下** |
| 169-170 | **他去救一个能救的人**（这是他的选择，也是他的罪） |
| **171** | **没赶上** |
| **172** | **苏老死。** 偏执点 A 必查位 |

### 禁止提前释放

- ch166 之前**不许写他与主角有任何师徒式的对话**（本世没有这一层）
- **F6 那页手稿的内容**在 ch172 之前不许出现
- **ch172 之后全书不许再死人**（硬纪律，写进卷五卷纲）

## 四、顾延龄（卷四-卷五 · 主角五十年的样子）★★

### 基本盘

| 项 | 内容 |
|---|---|
| 身份 | 表面：做医疗慈善与投资的老先生。六十多岁，儒雅、体面、说话温和 |
| 实质 | **也在改命的人。比主角早很多，完全理解锚点规则并且接受了** |
| 章位 | 107 / 115 / 129-131 / 136-142（卷四）· **143-162（卷五）** |
| **最高光** | **ch160：替他挡。** 用自己的"最后一次"顶上去<br>台词只有一句：**`"我不想看你变成我。"`** |

### 核心：他不是反派

> **他不是"要抢什么东西的人"，是走同一条路、早走了一步、并且接受了的人。**
> **他存在的意义不是制造冲突，是让主角看见自己五十年后的样子。**

| 项 | 内容 |
|---|---|
| 他的哲学 | **`"我救了三千个人，代价是三十个。这笔账是划算的。"`** |
| 与主题的接口 | 和主角"用她的命换自己的命"**完全同构**——只是他**算清了，并且心安理得** |
| **v4 重设** | 他是**说破过的沈亦舟**——他年轻时把话说出口了。**代价是永别** |
| 他挡的是什么 | **不是死，是那句话。**（规则：说破 = 永别） |

### 签名（写他只用这些）

| 项 | 内容 |
|---|---|
| **对话** | **≤20 字。句子里必带数字**（"三千""三十""最后一回"） |
| **问号** | **会问**（全书会问的四人之一） |
| **签名动作** | **他一直在算。** 不是算钱——他手里永远有个小本子，记的不是账 |
| **他的手** | 干净、白、没有茧。**他这辈子没亲手救过人** |

> **"他的手没有茧"是人物核心**：他救了三千个人，**一个都没有亲手碰过**。
> 主角的手有药碾子的茧。**这是他们唯一的、也是决定性的区别。**

### 章位表

| 章 | 内容 |
|---|---|
| 107 | 名字第一次出现（传闻："一个什么都知道的老先生"） |
| **115** | **第一次照面**（论道前）。他递了一句话就走，**主角当时没听懂**（F9） |
| 129-131 | 真相段对峙。**ch131：药厂那笔账**（F17：救了 3176 个，死了 29 个） |
| 136-142 | 卷末出手。为卷五铺垫，**读者此时还不知道他要干什么** |
| 143-159 | 卷五正面博弈。**他拦他，但拦得很有道理** |
| **160** | **替他挡。** `"我不想看你变成我。"` **全书对手线最高光** |
| 161-162 | 他不见了。**不还价，不告别**（偏执点：他不回头） |

### 回响句（三句，各带一个数字）

| # | 句子 | 章 |
|---|---|---|
| 1 | `"我救了三千个人，代价是三十个。这笔账是划算的。"` | ch131 |
| 2 | `"你想救的是那一个。我不是不想救，我是已经救过了。"` | ch155 |
| 3 | **`"我不想看你变成我。"`** | **ch160** |

### 四条铁律

1. **不许把他写成反派、不许让他做任何"恶事"**
2. **不许解释他的机制**（他也是怎么开始的，全书不写）
3. **他的每一次出现都必须比上一次更平静**
4. **ch161 之后他不许再出现**（走就走干净，不留遗书、不留信、不留东西）

### 禁止提前释放

- ch131 之前**不许点破"他也在改命"**
- ch155 之前**不许点破"他已经救过了"**
- **"我不想看你变成我"** 在 ch160 之前一次都不许出现（包括相似句式）

## 五、四人的共同接口（写之前最后读一遍）

| 人 | 他改了什么 | 结果 | 主题台阶 |
|---|---|---|---|
| **周晚** | **时机** | 改了。她还是走，日期一天不差 | 第一级：**时机不可移** |
| **铁柱** | **人**（改三次） | 改了。他还是死，而且是自己跑回来的 | 第二级：**人心不可移** |
| **苏老** | —（**他不在场**） | 能救，但不在 | 第三级：**他自己的选择** |
| **顾延龄** | —（**他接受了**） | 他救了三千个，代价三十个 | 第四级：**账算不平，人才能救** |

> **这四级台阶，一级比一级重，一级比一级指向他自己。**
> 到第四级他才明白：**问题从来不是"能不能改"，是"改了算谁的"。**
