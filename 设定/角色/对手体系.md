# 对手体系（全书五卷）

> **建立原因**：第二轮评估 R2（★★★★★）——卷二靠风口、卷三靠行情、卷四靠命运，**这些都不能打脸**。
> 爽文的对手必须是**人**：会反击、会记仇、会成长。
>
> **设计原则（四条，写每一张卡都要过一遍）**
>
> 1. **镜像原则**：每个对手是主角某一面的镜子。对手越像他，打脸越疼。
> 2. **不作恶原则**：反派不能蠢、不能靠使坏推进剧情。他的行为在他自己眼里必须是正当的。
> 3. **传承原则**：卷级对手不换完就消失。上一卷的对手要在下一卷以新身份出现一次。
> 4. **对手线独立**：对手有自己的目标，不是为了等主角来打脸才活着。

## 二、卷一 · 三个打脸对象（补卡）

### 李国强（舅舅）

| 项 | 设定 |
|---|---|
| 身份 | 老妈的哥哥。做建材，90 年代末先富起来的那批。有钱，嘴毒 |
| 轻视内容 | 当众羞辱"下岗工人这辈子就这样了" |
| 他为什么这么说话 | **不是坏**，是真的这么认为——他这辈子唯一信的就是"谁挣到钱谁有理" |
| 打脸设计 | ch003 第一次（当众问崩他三十万的生意）；**ch016 第二次（生日宴，原话奉还）** |
| 铁律 | ① 不借钱给亲戚（他的信条）；② 当众说过的话绝不收回；③ 服软的方式是"换个话题" |
| 说话习惯 | 声音大，爱用反问句，"你说是不是这个理" |
| 后期 | ch016 后不再正面冲突。卷二他生意出问题，主角没落井下石——**这是他后来彻底服的原因** |

> **注意**：F7 伏笔——ch003 那句"你爸这辈子就这样了"，ch016 原话奉还。

### 马长贵（教导主任）

| 项 | 设定 |
|---|---|
| 身份 | 校方。严厉、讲规矩、在教室里站了三十年 |
| 轻视内容 | 认定这孩子"油滑、不踏实、投机" |
| 他为什么这么说话 | 他见过太多聪明但不踏实的孩子后来出事。**他的判断是专业的，只是这次错了** |
| 打脸设计 | ch011 小（当众顶回）；**ch021 彻底改口** |
| 铁律 | ① 不以权压人（他从不公报私仇）；② 认错的方式是沉默加行动，绝不口头道歉；③ 不改口头禅 |
| 说话习惯 | 短句，爱用手势，"我教了三十年书" |
| 后期 | ch021 后成为隐性助力（推荐名额、背书）。**卷二升学线靠他一句话** |

> **写他的分寸**：他不是坏人，是一个**判断失误的好老师**。打脸之后要给他台阶——
> ch021 他改口的方式不是承认错误，是"我教了三十年书，头一回看走眼"。这句比道歉更体面。

### 刘虎 + 校外混混

| 项 | 设定 |
|---|---|
| 身份 | 五年级孩子王，收保护费；校外混混是几个不入流的社会青年 |
| 轻视内容 | 欺负低年级（不针对主角，主角是"管闲事"撞上的） |
| 打脸设计 | ch007 小（巧劲制服）；**ch017-019 大打脸（设局，让混混在自己人面前出丑，大人查不出是他干的）** |
| 铁律 | ① 混混可以写蠢（这是唯一允许蠢的反派）；② 刘虎不能写蠢——他后来成了主角最早的小弟 |
| 说话习惯 | 刘虎话少，混混话多且脏 |
| 后期 | ch019 后刘虎服气，卷二成为跑腿的。**这条线是主角"势力"的起点** |

## 三、卷二 · 许知言（同龄竞争者）★

| 项 | 设定 |
|---|---|
| 身份 | 初二转学来。父亲是市里干部，母亲是中学老师 |
| 外形 | 白衬衫永远干净，字写得像印刷体，书包里每本书都包了书皮 |
| **镜像关系** | **主角＝野路子的早慧 + 没资源；许知言＝系统培养的优秀 + 有资源。**<br>他看得起主角的聪明，看不起主角的做派（"不踏实"） |
| 争什么 | ① 竞赛名额；② 推荐名额；③ **温若的注意**（他正当地追求，不是抢）；④ 大人的认可 |
| **他不是反派** | 他真的优秀、守规矩、不背后使坏。他输，是因为**他不会输给一个不如他努力的人——但他输给了一个多活三辈子的人** |
| **他的成长线** | 卷三进金融/法律行业，成为姜淮那边的年轻人；卷四以"体面的失败者"身份再出现一次；**那时候他已经不嫉妒了，他是唯一一个当面问主角"你是不是早就知道"的人** |
| 铁律 | ① 不作弊、不告黑状；② 输了会记着，但记着是为了下次赢，不是害人；③ **从不贬低主角的出身**——他其实不在乎这个，是主角自己以为他在乎 |
| 说话习惯 | 书面语，句子完整，不急。生气的时候反而更客气 |
| **关键台词** | `"我练了十年，你凭什么一看就会。"`<br>——这是全书第一次有人问主角"凭什么"，也是唯一一次问到了点子上 |
| **回响句** | `"你不是比我聪明。你是比我多活了一辈子——这事我到三十岁才想明白。"`（卷四） |

### 打脸节奏

| 章 | 内容 | 强度 |
|---|---|---|
| ch033 | 初遇：竞赛名额，两人第一次交手 | 小（主角险胜） |
| ch046 | 推荐名额，许知言用"正规方式"赢了一局 | **主角输一次**（不许主角全胜） |
| ch058-060 | 最终局：主角用**正统的方式**赢了他——不是靠预知，是靠他这三年真的学过的东西 | 大（他服了） |

> **ch046 让主角输一次是必须的**。三卷打脸全胜会让读者麻木，也会让许知言这个角色失去分量。
> **ch058-060 的狠处**：主角赢的那一手，是他这一世**自己练出来的**，不是记忆里带来的。
> ——这是全书第一次暗示：**他最强的不是记忆，是他真的活过。**

## 四、卷二 · 康九（老练小老板）

| 项 | 设定 |
|---|---|
| 身份 | 电子城档口老板，三十多岁，混过社会，手上有一道疤 |
| 功能 | 主角在商业上**第一次吃亏**（被坑一次），然后反过来赢他 |
| 他的价值 | 教主角一件事：**生意不是你知道得多就赢，是别人愿意跟你做** |
| 铁律 | ① 坑人之前先请吃饭；② **不赖账**（这是他的底线）；③ 从不说自己讲义气 |
| 说话习惯 | 短，爱笑，说到关键点时会停顿一下再看你 |
| 结局 | ch063 和解 → 卷二末成为主角的第一个"大人朋友"。**卷三他是第一个愿意借钱给主角的人** |

### 章位

| 章 | 内容 |
|---|---|
| ch038 | 初次打交道（主角用未来信息压价，康九笑着认了） |
| ch042 | **被坑**：主角第一次知道"合同"这东西不是纸上写的算 |
| ch049 | 翻盘（主角用康九自己的规矩赢回来） |
| ch063 | 和解。康九请了顿饭，说了一句话：`"你这小孩，不像小孩。"` |

> **ch042 的坑必须让主角真疼**——不是亏钱，是**他发现自己不是全知**。这是卷二最重要的一次挫败。

## 五、卷三 · 姜淮（金融对手）★★

| 项 | 设定 |
|---|---|
| 身份 | 私募/资管。四十来岁，草根出身，靠宏观推演吃饭，不靠消息 |
| **核心功能** | **主角第一次遇到"算不准的人"** |
| 为什么是他 | 主角的优势是"知道未来"。但姜淮**能从公开信息推出同样的结论**，而且他推得出来——因为他推的是"结构"，主角记的是"结果" |
| **更狠的一层** | 姜淮是全书**唯一察觉主角"不对劲"的人**。他不猜测，他做记录——<br>他有一个本子，记了主角每一次"提前知道"的时间点 |
| 他问出的那句话 | `"你怎么什么都知道。"`<br>——全书唯一一次有人把这个问题问出口。主角用玩笑话挡过去，姜淮没追问，**但也没放下** |
| **他赢的那一局（ch088）** | 主角**第一次算错**：因为他改了某个变量，历史偏移了，他记忆里的"未来"失效了。<br>→ 不是当众羞辱，是**主角坐在屏幕前看着自己算错的数字**。这是全书最安静也最狠的一次打脸 |
| 结局 | ch102 他把那个本子交给主角：`"我记了六年，一个字没看懂。你自己留着吧。"`<br>——**一份别人替他记了六年的证据** |
| 铁律 | ① 不做内幕、不违法；② 输了就认，不找借口；③ **从不跟人说自己怀疑主角**，他只是记着 |
| 说话习惯 | 慢，数字说得极准，不用形容词。会突然问一个不相干的问题 |
| **回响句** | `"我不是不信你。我是不信这个世界上有人能一直对。"` |

### 章位

| 章 | 内容 |
|---|---|
| ch072 | 初遇（一场饭局，两人第一次交手，互相打量） |
| ch080 | 小交锋（同时看多一个品种，主角险胜） |
| **ch088** | **主角第一次算错**（大反转，姜淮赢） |
| ch095 | 姜淮问出那句话（在场只有他们两个） |
| ch102 | **卷三末：他交出本子**。许知言在场，两代对手同框 |

> **姜淮这条线的真正杀伤力在 ch102**：他记了六年，一个字没看懂，还是记。
> 这不是执着，是**一个人对自己判断力的尊重**——他知道自己没看错，所以他不放弃。

## 六、卷四 · 顾延龄（也在改命的人）★★★

> **全书最重要的对手。他不是反派，是主角五十年后的样子。**

| 项 | 设定 |
|---|---|
| 身份 | 表面：做医疗慈善与投资的老先生。六十多岁，儒雅、体面、说话温和 |
| 真相 | **他也在循环。** 他比主角早很多——经历的次数他自己也说不清（"我记不清了"） |
| **他的哲学** | `"我救了三千个人，代价是三十个。这笔账是划算的。"`<br>——他完全理解锚点规则，而且**他接受了**。他选择继续改，因为"总账是赚的" |
| 他和主角的差距 | **不是智商，是：他算清了账并且心安理得；主角算不清，也不肯算** |
| **他的行为动机** | 他一直在**阻止**别人改命（包括主角）。因为他认为"每一次改动都要有人付账，而付账的人往往不知道"。<br>**他把自己当成"管账的"** |
| 他不是坏人 | 他是一个**做了一辈子亏心事、但自认为在止损的人** |
| 他失去的那个人 | 他也有一个"小满"。救了很多次没救回来，最后他放弃了。<br>**从那以后他开始做"划算的买卖"** |
| 铁律 | ① **从不说谎**（他说的每一句都是真的——这是他最可怕的地方）；② 不威胁、不动手，只用信息和时机；③ 从不解释自己的动机，**只在最后解释一次** |
| 说话习惯 | 温和，句子长，会替对方把话说完。从不提高音量 |
| **回响句** | `"我不是拦你。我是怕你变成我。"` |

### 关键对峙（ch128-131 真相段）

> 顾：`"我不是拦你。我是怕你变成我。"`
> 沈：`"那你现在是什么？"`
> 顾：`"一个把账算平了的人。"`
> 顾：`"你算不平。"`

### 终局（ch160 · 全书对手线最高光）

- 主角最后一试，**窗口真的开了**。他只要迈出那一步就成了。
- **顾延龄替他挡了。** 他用自己的"最后一次"顶上去。
- 台词只有一句：`"我不想看你变成我。"`
- 之后：主角活下来，机会没了。顾延龄不见了。

> **这一笔把"有人替你挡"从主角身上扩展到了所有人。**
> 之前是"有人替他挡"；这里是"**一个算平了账的人，最后一次没算账**"。
> 主题在这里闭环：**账算不平，人才能救。**

| 章 | 内容 |
|---|---|
| ch107 | 名字第一次出现（传闻：一个"什么都知道"的老先生） |
| ch115 | 第一次照面（**论道前**。他递了一句话就走，主角当时没听懂） |
| ch128-131 | 真相段对峙（上面那段对话） |

## 八、卷五 · 方敬之（神医骗子）

| 项 | 设定 |
|---|---|
| 身份 | 靠包装成"神医"的流量中医。五十来岁，出书、上节目、有粉丝 |
| **镜像的是主角的哪一面** | 顾延龄＝**如果只算账不做人**；方敬之＝**如果只会技术不会做人** |
| 为什么卷五需要他 | 平淡段（ch181-190）不能没有冲突。他是卷五"打脸"的来源 |
| **他不是纯骗子** | 他有点真本事，只是把本事当生意卖。这比纯骗子难对付 |
| 打脸方式 | 不是骂战、不是撕。是**一个他治反了的病人，主角几副药治回来**。<br>当众，但不张扬 |
| 铁律 | ① 打完脸不赶尽杀绝；② 他后来**求过主角一次**（为一个真的病人）；③ 主角帮了 |
| 说话习惯 | 客气，语速快，爱引经典，从不说"我不知道" |
| 章位 | ch181-183 出现 / ch186-188 打脸（小、体面）/ ch189 他来求医 |

> **ch189 他来求医是必须的**：如果打完脸就结束，主角会显得刻薄。
> 让对手回来求一次，主角的"不争"才成立。

## 九、对手体系的四条硬纪律

| # | 纪律 |
|---|---|
| 1 | **每一卷至少有一个"人"的主对手。** 靠风口、行情、命运推进的章节，爽度一律不计分 |
| 2 | **主角不许全胜。** 卷二 ch046、卷三 ch088 各输一次（一次输给正统，一次输给判断力） |
| 3 | **对手不许在打脸后消失。** 李国强、马长贵、许知言、康九、姜淮都必须在后续卷出现至少一次 |
| 4 | **打脸必须给台阶。** 主角赢了之后要让对方体面——**体面的赢比羞辱的赢更爽，也更高级** |

## 十、爽度核算（章加权）

| 卷 | 章数 | 有对手的章 | 爽度 |
