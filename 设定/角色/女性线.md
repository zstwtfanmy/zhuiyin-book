## 一、乔蔓

| 项 | 内容 |
|---|---|
| **年龄** | 比他大三岁（卷三时 21） |
| **身份** | 卫校毕业 → 药店 / 后来的社区医院。**专业技术岗，不是花瓶** |
| **出现** | **ch062**（卷二末）：他病了，她照顾。**她退了** |
| **关系** | **ch074**（他 18）· **他的第一次** |
| **退出** | **ch080** |
| **退出台词** | **"我不想当第一个。"** |
| **签名动作** | 走之前把自己在他那儿的东西**清空，一件没留**（连一个发卡都没有） |
| **留给他的** | **"第一个"三个字**。他后来才懂：她不是要名分，**她要的是最后一个** |

### 她的内部逻辑（不能写出来的部分）

- 她是第一个看穿他的人：**ch062 她退，不是因为他小，是因为她看见他心里已经有人了。**
- **ch074 她答应，是明知道没结果还答应了。** 她不是被骗的，是她自己选的一次。
- **ch080 她走，是因为她发现自己正在变成"第一个"，而那不是她要的位置。**

### 纪律

1. **她不哭、不闹、不要说法。** 走的时候很平静，甚至还把药给他配齐了。
2. **她的职业线不能断**——她后来成了社区医院最能干的那个。**她的日子过得很好。**
3. **她的台词全书不超过 40 句**，且**从不问他"你心里是谁"**。
   → **她不问，是因为她已经知道答案。**
4. **她不嫉妒。** 她是六个人里唯一一个从不嫉妒的——**因为她从第一天就知道自己排不上号。**

> **疼点**：她是他第一个女人，也是第一个看穿他的人。
> **她判断的时机，比他早了整整一辈子。**

## 二、池遥

| 项 | 内容 |
|---|---|
| **年龄** | 与他同龄略大 |
| **身份** | 圈子边缘的人，**自己有事业，不缺钱，不缺人追** |
| **出现** | ch082 |
| **定调台词** | **"我不要你负责。你也别对我负责。"** |
| **关系** | ch086-090（**全书唯一一段没有重量的关系**） |
| **退出** | **ch090 之后自然消失。没打招呼，没交代，没告别** |
| **签名动作** | **从不留任何东西在他那儿。连一个发卡都没有。** |
| **留给他的** | **"没有重量"这件事本身** |

### 她的内部逻辑

- 她不是不在乎，是**她的人生本来就不需要从他这里拿东西**。
- 她走了也没打招呼，是**因为她觉得这不算一件事**。
  → **这一条最伤人：她甚至不认为这值得一个告别。**
- 她后来过得很好，且**在 ch187 旧人回访时可能路过一次**（不带感谢，只是路过）。

### 纪律

1. **不许写她吃了亏、不许写她委屈。她是六个人里唯一一个完全没受伤的。**
   → **这一条反而是最狠的：他连让人受伤的资格都没有。**
2. **她的消失不许有解释。** 后文最多用一句带过（"池遥后来去了南方"），**且不是他说的**。
3. **她与小满在 ch088 同章**——见 `亲密关系谱系.md` 第三节②。

## 三、周晚（第一世 · 补全）

| 项 | 内容 |
|---|---|
| **世代** | 第一世（金融）· 本世卷三重逢 |
| **身份** | 同行。**唯一一个看得懂他每一步的人** |
| **出现（本世）** | ch089 |
| **关系** | **ch090 一夜**。两个人都知道没有明天 |
| **退出** | **ch096-098**。**方式不同，日期和第一世一模一样** |
| **签名动作** | 走之前把他书架上一本**他没看过的书**抽走了。**没说** |
| **留给他的** | `"原来不是我没说，是我说了也没用。"` |

### 她的内部逻辑

- **第一世**：两个人都没开口，都在等对方先说。她走了。
- **本世**：他开口了。**她还是走。**
  → 因为她要的从来不是"他开不开口"，是**她自己的路**。
- **她抽走那本书，是一个只有他自己能发现的暗号**——
  **他过了很久才发现那本书不见了。**（回甘位 · 物）

### 纪律

1. **不许把她写成"因为误会/赌气/被抢走"而离开。**
   **没有反派、没有意外、没有误会，只有她要走了。**
2. **她走得最干脆**——六个人里唯一一个**当面说清楚**的。
3. **她是全书智力上唯一与他对等的人**，卷三的对话要能接住他。
   → 她的**对话签名**：**短句、反问、从不铺垫**。

## 四、岑玫

| 项 | 内容 |
|---|---|
| **年龄** | 与他同龄 |
| **身份** | 圈子里的人。**聪明、体面、不缺人追** |
| **出现** | ch126 |
| **性质** | 六条里**身体最多、心为零**的一段。**他自己也开始滥了的时期** |
| **转折** | **ch138**。她问：**"你到底在找谁？"** |
| **他的反应** | **答不上来。**（全书他答不上来的问题只有两个，这是第一个；第二个在论道 ch122） |
| **结束** | **当天。** 她自己走的 |
| **签名动作** | **她走的时候，把门带上了。全书唯一一次有人给他关门是轻的。** |
| **那杯水** | **ch138 他倒了水放在她那边。她没喝。** |

### 她的内部逻辑

- 她一开始就知道他心里有人，**她不在乎**（她自己也有自己的生活）。
- 她的耐心不是无限的：**她能接受"你心里有人"，不能接受"你一直在找她"。**
- **ch138 那一问不是质问，是陈述。** 她问完就已经走了，**不等答案。**
- **她走得甚至有点高兴**——**因为她终于不用再假装不知道了。**

### 纪律

1. **不许把她写成反派或"撕逼女配"。** 她体面、聪明、有分寸。
2. **那一问必须是从一个"最不重要的人"嘴里说出来的。**
   → **越不重要的人，说出来的真话越狠。**
3. **她没喝那杯水** —— 六次"一杯水"里唯一一次被拒绝，且拒绝得轻描淡写。
   **她连拒绝都懒得有情绪。**
4. **这一问直接把读者推向 ch115-125 的论道。中间不许有别的解释。**
