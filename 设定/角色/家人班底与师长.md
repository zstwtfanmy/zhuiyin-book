## 一、李秀兰（老妈）

| 项 | 内容 |
|---|---|
| **身份 / 行当** | 机床厂家属院的家属，纺织厂下岗女工，后来在菜场帮人卖菜、给人家做零工 |
| **目标** | 让这个家别散。她的全部力气花在"别出事"上，而不是"过得更好" |
| **关系** | 沈建国（丈夫，她护着但也嫌他软）／沈亦舟（儿子，她觉得这孩子最近"怪"）／李国强（她哥，她知道他嘴毒但毕竟是哥） |
| **知识边界** | 她知道家里没钱，**不知道儿子知道多少事**。她一辈子没弄明白儿子那些话是怎么来的 |
| **自我叙事 vs 事实** | 她以为自己"把家撑住了"；**事实是她每次都在最不该打岔的时候打岔**（丈夫被羞辱时她说"哥，吃饭了没"） |

### 行为铁律（喜剧载体）

1. **永远不在点上**——任何紧张场面，她都会插一句完全不相干的家常（"吃不吃西瓜""哥，吃饭了没"）
2. **她用"吃"处理一切情绪**——高兴做饭，难过做饭，不知道怎么办就盛饭
3. **从不正面顶撞任何人**，包括她哥；她唯一的反抗是"把碗放得重一点"
4. **她记得所有人的口味**，包括儿子不爱吃香菜（**这与陈小满的"记得"是同一件事，也是误读的来源**）
5. **任何情况下不质问丈夫"你怎么不吭声"**——她知道，所以不问

### 说话习惯

- 一句话上限 **≤15 字**；全是祈使句和问句（"洗手。""吃不吃？""回来了？"）
- **她的问题从来不需要回答**（"回来了？"——她已经看见你回来了）
- 口头禅：**"吃饭了没"**（这句在 ch196 老爸临终前会以另一种形式出现）
- 骂人只骂"你个死孩子"，不骂第二句

### 章位与功能

| 章 | 功能 |
|---|---|
| ch001 | "哥，吃饭了没，我给你盛。"——**在全章最屈辱的那一刻插一句家常**（喜剧层招⑥） |
| ch002 | "一直都没有啊。"——盖掉记忆偏移（**用最土的解释盖住最不寻常的事实**） |
| ch003 | "小孩别瞎问。" |
| ch012 | 她偷偷去打零工（母子线） |
| ch016 | 舅舅生日宴，她夹在中间 |
| ch196 | 老爸临终，她做的是饭 |

## 二、陈默（班底 · 技术）

| 项 | 内容 |
|---|---|
| **身份 / 行当** | 同班同学。家里开小卖部，父亲酗酒。后来是主角的技术合伙人 |
| **目标** | **会一样别人不会的东西**（这是他全部的自尊来源） |
| **关系** | 沈亦舟（他从心里服，但不问为什么）／王浩（玩伴）／父亲（怕） |
| **知识边界** | 他知道主角"看得两分钟就会"，**他不知道主角为什么**；他被明令不许问 |
| **自我叙事 vs 事实** | 他以为自己是"被带的"；**事实是他才是那个一直没走的人**（全书唯一从卷一到卷五都在的人） |

### 行为铁律

1. **不问"你怎么会"**——ch005 被明令，他记了一辈子
2. **手比嘴快**——他一紧张就动手（敲键盘、拆东西、拧螺丝）
3. **任何情况下不提自己家里的事**（手腕上的红印，全书只点两次，不解释）
4. **主角说"别做"的事他一定不做**——这是他唯一的原则
5. **他从不邀功**，做成一件事只说"好了"

### 说话习惯

- 一句话上限 **≤10 字**；技术话题会突然变长（**这是他唯一话多的时候**）
- 紧张时说"那个……"，然后没了
- 口头禅：**"好了。"**（做完了就说这两个字）

### 章位与功能

| 章 | 功能 |
|---|---|
| ch005 | 网吧落位。**"你这不是游戏。""那我问什么？""问你自己的。"** |
| ch013 | 班底成型（每周两次） |
| ch021 | 拉他入伙做生意 |
| ch029 | **跟不上了**（友情的第一次代价） |
| 卷三-卷五 | 技术合伙人；**ch187 旧人回访的其中一人** |

## 三、王浩（班底 · 接梗）

| 项 | 内容 |
|---|---|
| **身份 / 行当** | 同院/同班，脑子一般，人实诚。后来跟着主角做点小生意 |
| **目标** | 跟着有本事的人，**别掉队** |
| **关系** | 沈亦舟（发小，他这辈子唯一"跟对了"的一次）／陈默（一起玩） |
| **知识边界** | 他什么都不知道，也不需要知道——**他是全书的"读者代言人"** |
| **自我叙事 vs 事实** | 他以为自己"跟得挺紧"；**事实是他从 ch029 起就再也没跟上过** |

### 行为铁律（**他是全书第一接梗位**）

1. **任何超出理解的事，他都问同一句："真的假的？"**
2. **他替读者说出反应**——"你刚才那三句，我鸡皮疙瘩都起来了"
3. **他不嫉妒**——这是他能留到最后的原因
4. **任何情况下不装懂**（不懂就说"不懂"）
5. **他记不住道理，只记住人**（多年后他说不出主角教过什么，只记得"他那时候就这样"）

### 说话习惯

- 一句话上限 **≤12 字**；**问号极多**（他是"会问"的人，与主角的"不问"形成对照）
- 口头禅：**"真的假的？"**／**"你们俩干嘛去了？"**
- 他从不说完整的道理，最长的一句是"我妈说……"

### 章位与功能

| 章 | 功能 |
|---|---|
| ch001 | "真的假的？""看哪儿？"——**接梗位第一次开张** |
| ch002 | "你今天怎么跟换了个人似的。" |
| ch003 | "你刚才那三句，我鸡皮疙瘩都起来了。"（**围观者反应镜头**） |
| ch029 | 跟不上他了 |
| ch187 | **旧人回访**——他来了，不带感谢，只是路过 |

## 四、程守拙（论道对手）

> 详细论道设计见 `大纲/悟道_论道设计.md`，本卡只锁"人"。

| 项 | 内容 |
|---|---|
| **身份 / 行当** | 苏老的同门师弟。在临县开了一辈子小药铺，没出过名，被同行看不起 |
| **目标** | 无。他这辈子不追求任何东西（**这是他能点醒主角的前提**） |
| **关系** | 苏老（同门，一辈子没赶上）／主角（他不知道主角是谁，只知道"一个病人"） |
| **知识边界** | **他不知道陈小满是谁**（只说"一个病人"）／他不知道主角能改命 |
| **自我叙事 vs 事实** | 他以为自己是个失败的老头；**事实是他是全书唯一自由的人** |

### 行为铁律（喜剧与机锋的载体）

1. **全程不停手**——择菜、煎药、扫地。最狠的话都在干活间隙平着说出来
2. **从不给结论**——只反问（"你有病吗？""那你看她干什么？"）
3. **不劝、不教、不送**——他不是在教，是在**劝当年的自己**（他也失去过）
4. **任何情况下不提"师父""师门"**，也不认主角是同行
5. **最后推来一碗粥**："凉了。""凉了也得喝。"（**偏执点 A 的最高光**）

### 说话习惯

- 一句话上限 **≤20 字**；**反问句为主**；**会问**
- 手抖，撮药的时候会撒一点，他不在意
- 不说"你"，说"你这个病人"

### 章位

ch118-123（**ch122 是全书题眼**："你现在知道她有多难了。"）
