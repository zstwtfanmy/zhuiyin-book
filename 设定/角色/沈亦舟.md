# 沈亦舟（主角）

## 身份 / 行当

- 第一世：金融（2008-2015）｜第二世：特种兵（2015-2022）｜第三世：中医（2022-2026）
- 第四世：2000 年 9 月 1 日，小学三年级。1990 年生，回穿时 9 岁，体内 35 岁。
- **行当（人物之眼比喻的取材处）**：他看什么都先看成"方子"——
  看人看气色，看事看赔率，看场面看退路。三套职业病同时在线，互相打架。

## 目标

- 表层：让家里不穷、让身边人活得好、把每一世的遗憾一件件勾掉。
- 里层（他自己不承认）：**再见到小满，这一次护住她。**
- 深层（卷五才显形）：他想证明自己值得被她挡那三下。

## 关系

- 沈建国（父）：唯一他改成功的人 → 也是他最不敢失败的地方；
- 陈小满：他以为自己护她，实际是她护他（他卷五才知道）；
- 温若：他欠得最多、还得最少的人；
- 周晚 / 赵铁柱 / 苏老：三段旧账，三次"我本可以"。

## 知识边界（他知道什么 / 不知道什么）

| 知道 | 不知道 |
|---|---|
| 未来二十年的大方向（风口、灾、行情节点） | 任何能直接抄的细节（记忆按情绪存档，越有用越模糊） |
| 中医能治什么、治不了什么 | **第三世那个"没治好的病人"是谁**（卷五） |
| 有人出事时该做的第一件事 | **回穿的钥匙是执念**（卷五） |
| 每一次失去的**瞬间**（清清楚楚） | 每一次失去的**原因**（一无所知） |

> **自我认知差（黛玉机制）**：他坚信"我这次一定能改"。
> 读者从卷二起就看出——他改的每一件事，都在把她往那个位置上推。

## 自我叙事（他坚信什么 vs 读者所见事实）

- 他坚信：**"我活了四辈子，我比谁都看得开。"**
- 读者所见：**他是最放不下的那个。** 他所有的"不急""慢慢来""看开了"，
  都是因为他把唯一真正想要的东西排在所有事情的后面，假装它还在。
- **这个自我认知差就是"玩世不恭"的来源**——不是性格，是防御。

## 行为铁律（3-5 条）

1. **任何情况下，不主动说出自己的记忆来源。** 被逼到墙角就装小孩、装看书、装猜的。
2. **在能救的人面前，先救再说。** 哪怕代价事后才来（因此他才一次次错过苏老）。
3. **别人道谢时，必答一句不沾边的话。** 他受不了被认真感谢。
4. **在小满面前，任何情况下不提"以后"。** 他不敢许诺——这一条卷五才被读者读懂。
5. **从不在人前承认疼。** 疼的时候他会去干活：做饭、算账、擦桌子。

## 说话习惯

- 短句，句号多，几乎不用感叹号。越紧要的话说得越平。
- 答非所问型幽默：被夸时岔开，被问时反问，被逼时打哈哈。
- 三套记忆留下的口癖会串：
  算账时说"这个仓位不划算"，动手前说"先找掩体"，劝人时说"先扶正再祛邪"。
  ——前期是笑点，中期是病灶（串线越来越频繁）。
- **唯一不贫的时候**：提到小满。他一提她就句子变短、变直、变笨。

## 弧光（六卷）

| 卷 | 状态 |
|---|---|
| 卷一 | 老灵魂装小孩，玩世不恭是天性 |
| 卷二 | 开始享受"能改"的快感，第一次不安 |
| 卷三 | 第一次正式改锚点失败 → 他的"从容"出现第一道裂 |
| 卷四 | 三次改动三次失败 → 他开始急躁、开始用力过猛、开始伤人（温若） |
| 卷五 | 悟道：**明白了但没接受**，决定再赌一次 |
| 卷六 | 最后一次不去。**他终于活成了一个普通人——这是全书他赢得最彻底的一次** |
