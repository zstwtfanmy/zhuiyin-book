# 开篇钩子设计（ch001-003）v5

> **为什么单独立一份**：第四轮评估里**开篇钩子 8.5**，是三项待提升之一。
> 诊断：**现在的开篇是"他重生了"——这是最俗、最没有不可替代性的钩子。**
> 200 章的书，第一页必须有**别人抄不走的东西**。
>
> 参考：《庆余年》开篇范慎病死→婴儿；《活着》开篇老人与牛；
> 《诡秘之臣》开篇自杀现场。**共同点：先给一个结果，再倒回来看原因。**

---

## 一、倒叙钩子（ch001 前 200 字）★★★

> **先给"最后"，再给"最开始"。**

### 定稿文字（编排层照此写，不要发挥）

```
他四十七岁那年，在城南一家早点铺里，一个女人给他端了碗面。

面很烫。

他跟她说了一句话。说了半句，她打断了他。

"趁热。"她说。

那是他这辈子最后一次开口。

——

风扇在头顶转。粉笔灰在光里飘。讲台上有人点名。

"沈亦舟。"

"到。"

他低头看自己的手。九岁的手。
```

### 为什么这样写

| 设计 | 作用 |
|---|---|
| 一个女人端了碗面 | 读者不知道她是谁。**这是全书最长的钩子——要等 183 章** |
| **说了半句，她打断了他** | **与 ch101 温若「差点说破」完全对称**：<br>温若说半句，被他打断；他说半句，被小满打断。<br>**他这辈子既没让人说完，自己也没说完过。** |
| "趁热" | 第一次出现读者不在意。**ch183 第二次出现时，读者会浑身发冷** |
| 那是他这辈子最后一次开口 | 建立规则：**他每一世只开一次口。** 读者读到 ch183 才懂 |
| 九岁的手 | 落"手"，符合镜头习惯（语言纪律第三节） |

### 六条硬纪律

1. **不许解释。** 不写"他重生了"、不写"前世"、不写这是第几世。**这四个字全书禁用。**
2. **这一段 ≤200 字，之后 200 章不再出现任何闪回。**
   → 这样它既不违背"前两世只是背景"，又是最强钩子。
3. **不写那个女人的长相、名字、年纪。** 只写"一个女人"。
4. **不写他说了什么。** 全书都不写。
5. **破折号是这一段唯一允许使用的地方**（语言纪律禁用破折号，此处特批一次）。
6. **读者读完后应该有三个问题**：她是谁？他说了什么？为什么是最后一次？

> **最后一个问题的答案，全书不给。**
> ch160 顾延龄那句"我不想看你变成我"是最近的暗示，但仍不点破。

## 二、ch001 主线：小打脸 + 穷 + 老爸

> 原设计 ch001 的爽点是"路上噎住邻居（微）"——**太弱了，撑不住黄金三章的第一章。**

### 2.1 小打脸：望诊说中邻居家孩子的病 ★

| 拍 | 内容 |
|---|---|
| 1 | 放学路上，他看了邻居家三四岁的孩子一眼。多看了两秒 |
| 2 | 他跟孩子妈说了句什么（**不许写诊断术语，只写一句大白话**） |
| 3 | 邻居不当回事——一个九岁小孩懂什么 |
| 4 | 当天夜里孩子抽搐，送医院 |
| 5 | **医生说的话跟他一字不差**（这一句必须原样重复他说的那句大白话） |
| 6 | **围观者反应**：院子里炸了。第二天大人们在院门口等他放学 |

**为什么这一笔比原设计强**：
- 是**专业爽**（望诊），不是嘴皮子爽；
- 有**围观者**（打脸必须有旁观者，这是总纲硬规矩）；
- 有**降维**（大人办不到，小孩办到了）；
- **不刻薄**——他是在救人，不是怼人。**符合本书"体面的赢"的调性**；
- 它为后面所有的"望诊"建立可信度。**一次立住，后面都省事。**

**纪律**：他说的那句大白话**不许高明**，必须土、必须像小孩会说的话。
→ 越是"土话"，医生一字不差地重复时越爽。

### 2.2 穷与被欺负：舅舅那句话提前到 ch001

> **原设计 F7（"你爸这辈子就这样了"）在 ch003，太晚。**

**改法**：**他放学回家，隔着门听见舅舅在屋里说。**

- 不是对他说——是**背地里说的**。更狠，也更真实；
- 他站在门外听完了，然后推门进去，**什么都没提**；
- **老妈在厨房，没听见。老爸在里屋，听见了，没出来。**

> **这一笔同时立住三件事**：
> ① 家里穷，且**是被亲戚定义的穷**；
> ② **老爸的处境**（被羞辱但不吭声——呼应他后来"一生气就转去做事"）；
> ③ **主角的性格**：他从小就会忍，**而且忍下来之后会记账**。

**纪律**：**不许写他的愤怒。** 只写他推门、放下书包、去厨房看了一眼。

### 2.3 老爸（父子线立住）

- 他给老爸倒了一杯水。**杯把手朝外**（F1 第一次出现）。
- **望诊老爸**：脸色、眼白、手。他心里有了数。
- **不点破。** 只写他多看了两眼。

> **这三件事（小打脸 / 舅舅的话 / 老爸）必须在 ch001 全部落地。**
> 第一章要让读者知道：这孩子有本事、这家很穷、他爸有病。

## 三、黄金三章重排

| 章 | 内容 | 爽 | 情 |
|---|---|---|---|
| **001** | 倒叙钩子（200字）→ 醒来九岁 → **望诊小打脸** → **隔门听见舅舅那句话** → **给老爸倒水（杯把手朝外）** | **小打脸** | 父子 + 屈辱 |
| **002** | 开学。她把热的留给他（**误读前的纯善意**）→ 他第一次去她家铺子 → 老爸的身体有反应了 | — | **小满落位 + 父子** |
| **003** | **订金：舅舅上门 → 大打脸**。最后一句"我听我爸说的"，把功劳推给老爸 | **大打脸** | 家族 + 老爸的尊严 |

### 三章的三个交代（读者读完之后必须知道）

1. **他不是普通小孩**（望诊 + 订金）；
2. **这家很穷，但有人护着**（舅舅 vs 老爸）；
3. **有个姑娘对他好**（ch002 那口热的）。

### 三章必须埋下的四颗种子

| 种子 | 章 | 回收 |
|---|---|---|
| F1 那杯水（杯把手朝外） | ch001 | ch194 老爸临终 |
| F7 舅舅那句话 | ch001（提前） | ch016 彻底打脸（原话奉还） |
| 倒叙钩子的三个问题 | ch001 | ch183（读者自己想起来） |
| 她把热的留给他 | ch002 | **不回收**（v4：它只是善意） |

> 详见 `作者性/语言纪律.md` 第五节。
