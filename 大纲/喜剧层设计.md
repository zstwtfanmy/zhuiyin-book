# 喜剧层设计（v9 · 地气与笑点）

> **为什么单独立一份**：前八轮把"克制、白描、三不写"立成了铁律，但**这本书目前没有一层地气**。
> 主角是个活了三辈子、什么都懂、永远在忍的人——**他不好玩。** 一个不好玩的主角，读者不会陪他走 200 章。
>
> 更危险的是：**纯克制的书会变成一本"很好但没人看完"的书。**
>
> **本文件的任务**：给这本书装一层喜剧皮，而这层皮必须能被后面的刀扎穿。

---

## 零、先核准：周星驰到底在笑什么

> 搜索核准（百度百科 / 新浪娱乐 / 影评）：无厘头的核心不是搞笑，是**"以近乎天真的认真回应现实"**。
> 特征：答非所问、偷换概念、逻辑跳跃、重复台词、戏仿拼贴、**"一本正经地胡说八道"**。
> 内核：**悲喜交融——"第一遍看笑料，第二遍看懂委屈，第三遍共情人生。"**

### 最关键的两条（决定本书能不能学）

| 核准结论 | 与本书的关系 |
|---|---|
| **"以近乎天真的认真回应现实"** | **这就是主角的本体。** 他是一个知道结局的人，在一个所有人都不认真的世界里；他认真到为了一句话憋一辈子，而世界一直在开玩笑 |
| **"第一遍笑料，第二遍委屈"** | **这正是 v4「误读清单」的喜剧版。** 那 17 处误读本来就长着喜剧的形状——他每误读一次，读者笑一次；回头看，全是刀 |
| **"我养你啊"之所以动人，因为说话的人自己都养不活自己** | **承诺的荒诞性与真挚性的撕裂** —— 本书 ch101 温若、ch160 顾延龄、ch183 一碗面，全在这条上 |

> **结论**：周星驰的喜剧和本书**不是拼接，是同构**。
> **他拍的是"小人物用荒诞对抗不堪"，本书写的是"一个知道答案的人，用认真对抗一个不肯给他答案的世界"。**
> **迁移的正当性成立，而且是全书最自然的一层。**

## 一、七招迁移（逐条给落点）

> **总原则：学招式，不学台词；学结构，不学段子。**
> 全书**不出现任何一句周星驰电影的原台词**，也不用"小强""旺财"这类现成符号。
> 致敬是**骨架的致敬**，不是彩蛋的堆砌。

### 招 ① 一本正经地胡说八道 ★★★★★

**原招**：用最严肃的态度，说最不靠谱的话（《国产凌凌漆》的"要你命三千"、《食神》的"折凳"）。

**本书落法**：**主角说真话，但没人信，因为说真话的是个九岁小孩。**

- 他讲的每一句都是真的（订金、杠杆、肝气郁结、非典、6124），**但语气像一个小孩在背课文**；
- 大人们笑，不是因为他错，**是因为一个小孩不该知道这些**；
- **笑点在"错位"，不在"荒诞"。** 他说得越认真、越平板，越好笑。

| 章 | 台词形态（示例） |
|---|---|
| ch003 | 他给舅舅画了一黑板"订金为什么是三十万的三倍"，**用的是小学算术**。舅舅听不懂，但算得对 |
| ch012 | 马主任训他"不踏实"，他认真解释"我这个不是不踏实，是提前把结果算出来了"，马主任更火了 |
| ch019 | 他劝老爸下海，用的是"咱家这个情况，属于典型的……"——**"典型"这个词从一个九岁小孩嘴里出来** |

> **纪律**：他说的时候**不许有得意、不许有笑**。他只是把话说完。
> **笑的是别人，不是他。** —— 这一条是主角人设的基石：**他一辈子都不觉得自己可笑，也不觉得自己了不起。**

### 招 ② 重复与变奏（回炉三次）★★★★★

**原招**：同一句台词在不同情境重复，最后一次变刀（"他好像一条狗"）。

**本书落法**：**五句最俗的俗话，全书各用三次。第一次好笑，第二次不好笑，第三次是刀。**

| 俗话 | 第一次（笑） | 第二次（不笑） | 第三次（刀） |
|---|---|---|---|
| **"这事儿包在我身上"** | ch008 他对王浩说，办成了 | ch096 他对周晚说，没办成 | ch113 他想对铁柱说，**没说出口** |
| **"吃饭了没"** | ch002 小满妈问他 | ch057 他每周去吃面时的寒暄 | ch183 **她说"趁热"，他没答上"吃了"** |
| **"你忙你的"** | ch016 老妈对他 | ch088 **她对他说**（他在忙，那句话他没接） | ch175 温若交接时说的最后一句 |
| **"回头再说"** | ch011 陈默拖延 | ch101 温若话到嘴边，他说了这句 | ch160 **顾延龄**（没有回头） |
| **"我没事"** | ch016 老妈说的 | ch053 小满没考上高中时说的 | ch196 **老爸临终**（最后一次） |

> **这五句话全是废话。全书最疼的五处，用的全是废话。**
> **周星驰的招法在这里真正生效：第三次出现时，读者不是被感动，是被"原来这句话是这个意思"击中。**
>
> **硬纪律**：这五句话**全书不许有第四次**，且**第三次出现时不允许有任何渲染**（不加破折号、不加省略号、不加心理描写）。

### 招 ③ 降格（把大的拉到地上）★★★★☆

**原招**：崇高的东西被拉到地面（狮吼功、黯然销魂饭）。

**本书落法**：**所有"大事"都必须有一个土的容器。**

| 大事 | 土的容器 |
|---|---|
| 第一笔五位数现金（ch028） | **用装咸菜的塑料袋装着，放在饭桌上** |
| 九位数身家 | 他记账还是用**一本软皮抄**，封面印着"劳动模范" |
| 论道（ch122 题眼） | 程守拙那句最关键的话，是**在择芹菜的时候说的** |
| 救 3176 个人的那笔账（ch129） | 账目第一次出现，是**写在一张药方背面** |

> **纪律**：**越大的事，容器越土。** 这一条同时也是"体面的赢"的视觉签名。

### 招 ④ 错位应答（答非所问，但答的是真的）★★★★☆

**原招**：对白答非所问、逻辑跳跃（《唐伯虎点秋香》对穿）。

**本书落法**：**只给一个人用——程守拙。**（论道的机锋对白天然就是错位应答）

| 场景 | 他问 | 程守拙答 |
|---|---|---|
| ch119 | "能不能改？" | "你那药煎糊了。" |
| ch120 | "我算错了吗？" | "你吃饭了吗？" |
| ch122 | "那我该怎么做？" | **"你先跟我说说，那个病人爱吃什么。"** |

> **纪律**：**主角是全书最不会开玩笑的人。错位应答只属于程守拙和配角，主角永远正面回答。**
> 因为**主角一辈子都在找答案，他没有余裕开玩笑**——这一条本身就是人物。

### 招 ⑤ 道具喜剧 ★★★★☆

**原招**：道具比台词重要（吹风机剃须刀、折凳、棒棒糖、如来神掌秘籍）。

**本书落法**：**三个"越破越厉害"的道具。**

| 道具 | 出处 | 复沓 |
|---|---|---|
| **软皮抄**（印"劳动模范"） | ch009 老妈单位发的 | 记账一辈子，ch129 药厂那笔账写在它上面 |
| **药碾子**（他的手有茧） | ch011 | 一辈子带着，ch188 给了学生 |
| **保温桶**（小满家的） | ch002 她给他留热的 | **他一辈子用的都是这个牌子** |

> **加一条周星驰式的"秘籍"**：**《赤脚医生手册》**——他三辈子最强的本事，来自一本**1970 年代的、掉了页的、一块二一本**的册子。
> ch011 他在废品站花两毛钱买的。**全书最贵的道理，装在最便宜的书里。**（《西游降魔篇》儿歌三百首 = 大日如来真经）

### 招 ⑥ 班底接梗（固定配角）★★★☆☆

**原招**：吴孟达 / 林子聪 / 元华——**固定班底才能接住无厘头的节奏**。

**本书落法**：**每个配角接梗的方式是固定的，且各不相同。**

| 角色 | 接梗方式（固定，不变） |
|---|---|
| **陈默** | **永远慢半拍。** 别人都笑完了他才反应过来，然后补一句更土的 |
| **王浩** | **永远捧哏。** "真的假的""然后呢""你再说一遍" |
| **老妈** | **永远不在点上。** 别人在谈生意，她问"你们吃不吃西瓜" |
| **舅舅李国强** | **永远听不懂，但永远不服。** 他接的每一句都是"你少来这套" |
| **马长贵** | **永远把小事上纲上线。** 越严肃越可笑 |
| **康九** | **永远客气。** 客气到可怕，笑着把话说死 |

> **纪律**：**接梗角色不许在严肃场景接梗。**
> 第一次出现"他没接"的时候，读者会立刻知道出事了 —— **"陈默这次没笑"** 是全书最好用的一根针。

### 招 ⑦ 悲喜同构（笑到最后都是疼的）★★★★★

**原招**："想拍的其实是悲剧，不知怎的出来成了喜剧。"

**本书落法**：**笑点配额递减律**（见第二节）。
**笑点不是装饰，是一把尺子——它消失的那一刻，读者心里一沉。**

> **这是喜剧层唯一真正服务于主题的功能。**
> 前六招让读者放松，第七招让读者在放松之后无处可躲。

## 二、笑点配额递减律 ★★★★★

> **公式：笑点密度 = f(1 / 情感温度)。**
> **越靠近小满、老爸的病、论道、任何一场失去，笑点越少，直到归零。**

| 卷 | 每章笑点配额 | 说明 |
|---|---|---|
| 卷一（001-026） | **3-5 个** | 最密。童年、亲戚、校园、生意，全是俗世层 |
| 卷二（027-064） | **2-3 个** | 开始有"不好笑"的笑点 |
| 卷三（065-102） | **1-2 个** | 笑点开始带针 |
| 卷四（103-142） | **0-1 个**，且集中在前半 | **ch114 之后全书归零** |
| 卷五（143-200） | **0** | 唯一例外：ch181-190 诊所日常有 2-3 处**笑里带针**的轻喜剧 |

### 四条执行细则

1. **ch114（铁柱死）到 ch200，全书不许再有一个笑点。**
   → 86 章无笑。**读者的不适应，就是钝痛本身。**
2. **卷五的"笑里带针"**必须长这样：一个真笑点，读者笑完立刻意识到他自己刚才在笑什么。
   → 例：ch187 旧人回访，那人说了句当年很好笑的口头禅，**这次没人笑**。
3. **每一个"该笑而没笑"的地方，必须用一句话点出"没笑"这件事**：
   → `陈默这次没接。` ／ `老妈那句"吃不吃西瓜"，这天没问。`
4. **★ 笑点 = 0，暖意不设限**（v9 补，解 N12）★
   → **86 章无笑不等于 86 章无趣。** 那是全书最大的商业风险。
   → **禁止的是"笑"，不是"轻"。** 以下全部允许，而且要多写：

| 允许的"轻" | 例 |
|---|---|
| 病人的孩子（说童言） | 小孩问他"打针疼不疼"，他说"疼"，小孩说"那你别打我" |
| 学生的笨拙 | 学生抓药把秤砣掉地上，他没说话，弯腰捡起来 |
| 日常的重复 | 每天早晨开门、扫地、烧水。**写三次，一次比一次短** |
| 天气和食物 | 阳光、面的热气、院里晾的被子 |
| 别人对他的善意 | 邻居送来的几个鸡蛋（**他每次都忘了吃**） |

> **判断标准**：**让读者嘴角动一下的，是笑点（禁止）；让读者胸口暖一下的，是暖意（鼓励）。**
> **卷五要的是"活着"，不是"好笑"。**

### 卷五"笑里带针"的三个具体设计（不许只用原则）

| 章 | 笑点 | 针 |
|---|---|---|
| ch184 | 一个病人进来，说了一大堆症状，他三句话问出来。**病人说"神了"** | 他没笑。**因为他想起苏老当年也是这么被叫的** |
| ch187 | 旧人回访，说了当年那句口头禅 | **这次没人笑。** 那人说了一半停了 |
| ch189 | 方敬之来求医，姿态很低，客气得像换了个人 | 他照常开方子。**一句旧账没提** |

## 三、俗套：俗在对话，雅在叙述 ★★★★★

> 用户原话：**"平常对话可以俗套。"**
> **这条是对的，而且应该推到底——因为生活本身就是俗套的。**

### 原则

| 层 | 要求 |
|---|---|
| **对话** | **允许、鼓励俗套。** 陈词滥调、套话、客套、场面话、邻里闲扯，全都可以。甚至**要故意用最没信息量的那种话** |
| **叙述** | **保持白描。** 一句都不许油滑 |

> **这个反差本身就是风格**：人物说着最俗的话，而叙述用最干净的语言看着他们。
> **读者会感到"这就是生活"，而不是"这是网文"。**

### 俗套对话的四种合法用法

| # | 用法 | 例 |
|---|---|---|
| 1 | **客套即距离** | 小满对他的称呼越来越客气（"你"→"沈医生"→"沈总"）。**客套话的密度 = 距离** |
| 2 | **套话即逃避** | 他回答所有情感问题都用套话："挺好的""都行""你看着办" |
| 3 | **闲扯即日子** | 院里大人的闲扯（谁家孩子、谁家菜价）**不推进情节，但建立世界** |
| 4 | **口头禅即人** | 每人一句口头禅，全书不变。见第六节 |

### 三条硬纪律（否则会掉价）

1. **不许出现网络流行语。** 他会活到 2030 年，说 2026 年的梗，三年就过时。
   → **周星驰式的笑点靠情境错位，不靠流行语。** 这是它能放十年的原因。
2. **不许为了搞笑打断叙事节奏。** 一个笑点超过 200 字，删。
3. **笑点不朝下。** 可以笑势利眼舅舅、笑骗子、笑官僚、笑装腔作势的人——
   **不许笑老实人、不许笑穷人、不许笑主角的家人。**
   → **周星驰的笑点从来不朝下。** 这是他的喜剧有人味的根本原因。

## 四、致敬清单（12 部，招式致敬，落到章位）

> **不抄台词，不用彩蛋，不点名。** 只用**结构**。

| 作品 | 取哪一招 | 落到哪 |
|---|---|---|
| **《国产凌凌漆》** | 用最严肃的态度推销最没用的东西（要你命三千） | ch003：他给舅舅一本正经讲订金原理，**用的是小学算术，工具是一根粉笔** |
| **《喜剧之王》** | 认真对待一件没人当真的事（排《雷雨》、"我养你啊"的荒诞与真挚） | ch012：他认真跟马主任解释一件小事，马主任越听越火。<br>**"我养你啊"的撕裂感** → ch101 温若 |
| **《食神》** | 折凳——最土的东西是最强的；大赛上的"黯然销魂饭" | ch028 塑料袋装钱；**ch186 几副药治回来，当众，不张扬** |
| **《功夫》** | 高手隐于市（猪笼城寨）；棒棒糖（童心 = 最强） | ch007 用巧劲制服刘虎；**ch166 最后一次暴起**；<br>棒棒糖 = **ch183 那个荷包蛋** |
| **《大话西游》** | 先给最真的情话，再一巴掌打回现实（"他好像一条狗"） | **ch101 温若差点说破 → 被打断**；<br>"他好像一条狗" → **ch200 终章那句自嘲** |
| **《九品芝麻官》** | 用嘴皮子打赢一件根本不该赢的事 | ch020 舅舅生日宴 |
| **《少林足球》** | 把最没用的东西组装成最强的（捡破烂的组队） | ch005 陈默在网吧学编程；ch021 拉王浩、陈默入伙 |
| **《长江七号》** | 穷人的体面（"我们虽然穷，但不说谎"） | **ch001 老爸被羞辱，没出声**；ch016 老妈偷偷打零工 |
| **《西游降魔篇》** | 儿歌三百首 = 大日如来真经（最幼稚的是最真的） | **ch011 《赤脚医生手册》**（两毛钱）；<br>**ch122 程守拙用最土的话说出题眼** |
| **《唐伯虎点秋香》** | 对穿 / 错位应答 / 广告式展示 | ch119-122 论道的机锋对白 |
| **《破坏之王》** | "我不是针对你……" | 马长贵（他每次训话都要先说"我不是针对你"） |
| **《审死官》** | 用规矩打败规矩 | ch049 用康九自己的规矩赢回来 |

> **验收**：这 12 处里，读者能认出 **3-4 处**算成功。
> **认出 12 处说明你在抄；一处都认不出说明你没学。**

## 五、八条硬纪律（这是"有人味"和"掉价"的分界线）

| # | 纪律 |
|---|---|
| **1** | **笑点只在俗世层。** 亲戚、同学、生意、路人、官僚、骗子。**笑点绝不落在小满、老爸的病、论道、任何一场失去上** |
| **2** | **主角自己不搞笑。** 他只是认真地说真话，**笑的是别人** |
| **3** | **不许网络流行语**（见第三节） |
| **4** | **笑点必须有信息量**——要么推进情节，要么暴露人物。**纯抖机灵删掉** |
| **5** | **被笑的人不许是弱者**（笑点不朝下） |
| **6** | **接梗角色在严肃场景必须"没接"。** 每次"没接"都是一根针 |
| **7** | **致敬用招式，不用台词。** 全书不出现周星驰电影原句 |
| **8** | **ch114 之后笑点归零，卷五只许有"笑里带针"** |
