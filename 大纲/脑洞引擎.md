# 脑洞引擎（v9 · 钩子与推进机制）

> **为什么单独立一份**：前八轮解决的是"这本书好不好"，本文件解决的是——
> **"读者凭什么点开第一章，并且不放下。"**
>
> **核心判断**：改命文 / 重生文已经被写烂了。**"他重生了"是全网最没有不可替代性的钩子。**
> 要"一下被吸引"，靠的不是更大的设定，是**别人没有的悬念形态**。
>
> **本文件的十个机制全部满足一条硬标准**：
> **它必须能被读者参与（能猜、能记、能对答案），而不是被读者旁观。**
> 旁观型设定会被忘记，参与型设定会长出追读。

---

## 零、总设计：三层信息差

> **读者 > 主角 > 配角。** 全书任何时刻，读者知道的一定比主角多一点点，但永远少一个关键答案。

| 层 | 知道什么 | 不知道什么 |
|---|---|---|
| **读者** | 结局的残片（倒叙钩子、卷首结果页）、他后悔过、有人在替他挡 | **他后悔的是什么** ← 全书最长的一根线 |
| **主角** | 三世的"结果"（他知道谁会死、哪年涨） | **过程的全部**（他记不清为什么、也说不清自己后悔什么） |
| **配角** | 只有当下 | 一切 |

> **这是全书最重要的一个结构决定**：
> **一个连主角自己都答不上来的问题，是唯一能让读者追 200 章的问题。**
> 因为主角不会在第三十章就把它解决了——**他根本不知道问题在哪。**

## 一、脑洞 ①：代价可视化账本 ★★★★★

> **已有设定**：代价守恒（他救一个，别处少一点）。
> **问题**：它是抽象的，读者感觉不到。
> **脑洞**：**把它变成每一章看得见的东西，让读者自己记账。**

### 机制

**他每改一件大事的第二天，世界上就会出现一件"和他完全不相干的小祸"。**

| 他赢的 | 第二天的小祸 | 章 |
|---|---|---|
| ch001 望诊救了邻居家孩子 | 院里张家晾的被子被风吹下楼，砸了自行车 | ch002 一句带过 |
| ch003 订金那笔 | 舅舅的货车在高速上爆胎 | ch004 |
| ch020 生日宴打脸 | 同桌一个不认识的人，第二天丢了工作 | ch021 |
| （读者开始自己找） | … | … |

### 四条纪律

| # | 纪律 |
|---|---|
| 1 | **小祸必须是真的"小"**，且**永远只写一行**，不加评论、不回头看 |
| 2 | **全书不许有任何角色把这两件事联系起来**——直到 ch131 |
| 3 | **读者第一次发现"原来是有配比的"，应该在卷三（ch087 前后）。**<br>不点破，只让细心的读者自己毛骨悚然 |
| 4 | **不许让主角注意到。** 他一辈子没发现过这件事（ch131 是唯一一次） |

### ★ 防"太巧"：小祸选取规则（v9 补，解 N10）

> **风险**：如果每一次赢都精准配一次祸，读者会说是"机械降神"，不是命运。
> **解法两条**：

**① 类型必须随机，且必须琐碎。**

| 可用 | 不可用 |
|---|---|
| 谁家丢了东西 / 摔了腿 / 吵了架 / 停了水 / 生意黄了 / 丢了一只猫 | 任何和主角**有关联**的人 |
| 都是真的"小"，没有一件是"大事" | 任何**可追责**的事（不能看起来像有人害的） |

**② 必须有三次"反证"——他赢了，第二天什么都没发生。**

| 章 | 反证 |
|---|---|
| 第一次 | 他等着出事。什么都没出。**他松了口气** |
| 第二次 | 还是什么都没有。他开始怀疑自己记错了 |
| **第三次** | **什么都没有。而这一次的赢，是全书最大的一次。** |

> **第三次反证是全书最阴的一笔**：
> 读者已经学会"赢了必有祸"，这次没有——**读者和他一起松了口气。**
> **然后 ch131 他数了一遍账，发现数目对不上。少的那几笔，不是没发生，是有人替他付了。**
>
> **防"太巧"的真正解法不是减少配比，是让读者先建立规律、再发现规律是假的。**

## 一点五、她不入镜的"俗解释"规则（v9 补，解 N11）

> **风险**：不入镜容易被读成灵异 / 玄幻，破坏本书的现实向。
> **解法（同时是喜剧层招③「降格」）**：
>
> **每一次不入镜，现场必须有一个人给一个俗气的解释。**

| 章 | 不入镜 | 现场必须有人说 |
|---|---|---|
| ch002 | 班级合影她那个位置糊了 | "这相机不行。"／"洗印店的问题。" |
| **ch053** | **初中毕业照，她闭眼了**（与"她没考上那所高中"同一天） | "她就这毛病，照相必闭眼。" |
| ch073 | 手机里没有她的照片 | （他自己没意识到，无解释） |
| ch107 | 他专门拍，曝光过度 | "这破手机。"——**他自己说的** |
| ch134 | 举起又放下 | — |
| ch183 | 想拍，没拍 | — |

> **纪律**：**俗解释必须是真的俗、真的可信。** 不许用"诡异 / 奇怪 / 说不清"这类词——
> **写了就等于告诉读者这是设定。**
>
> **用一个最土的解释，盖住一个最不寻常的事实。**
> **——这一条本身就是周星驰式的：用最土的话解释最怪的事。**

### 兑现

- **ch129**：药厂那笔账——救了 **3176** 个，死了 **29** 个。
- **ch131**：他翻旧账，把这辈子记下的"小祸"数了一遍。
  → **数字对不上。** 他记的，比该有的少。
  → **因为有些账，有人替他付了，他不知道。**

> **这一笔是全书最硬的"真相"**：不是"救人要付出代价"，
> 是**"你以为你付过账了，其实你没有——有人替你付了，而且没告诉你。"**

## 二、脑洞 ②：她不入镜 ★★★★★

> **已有设定**：她是锚点，锚点不可移。
> **脑洞**：**锚点不留痕——她这辈子没有一张清楚的照片。**

### 机制

| 章 | 呈现 | 读者的第一反应 |
|---|---|---|
| **ch002** | 班级合影洗出来，**她在的那个位置是糊的** | 印刷问题 |
| **ch053** | 毕业照，她闭眼了（同一天她没考上那所高中） | 运气不好 |
| ch073 | 他换了手机，发现所有人的照片都有，**唯独没有她的** | 巧合 |
| ch107 | 他专门拍了一张。洗出来曝光过度 | 相机坏了 |
| ch134 | 他举起手机，放下 | — |
| **ch183** | **他想拍一张。没拍。** | — |

### 三条纪律

| # | 纪律 |
|---|---|
| 1 | **全书不许解释原因。** 一次都不许 |
| 2 | **不许用"诡异""奇怪""说不清"这类词**——写了就等于告诉读者这是设定 |
| 3 | **他从头到尾没意识到这件事。** 他只是"一直没拍成" |

> **这是全书唯一一个"视觉的刀"**：读者回头翻 ch002 那张合影的时候，会知道那不是印刷问题。
> **而她入镜的那一次是 ch183——那碗面。但那一章没有照片。**

## 三、脑洞 ③：金手指是失忆症 ★★★★★

> **已有设定**：他知道结果，记不清过程（情绪强度存档）。
> **脑洞**：**这不是金手指，这是一种病。而它是有名字的。**

### 机制的三个表现

| 表现 | 例 |
|---|---|
| **会做，写不出步骤** | ch002 老师叫他上黑板，他写对了答案，写不出过程。**全班笑。** 老师说他抄的 |
| **能背结果，说不清理由** | ch019 他能说出十年后某只股票的收盘价，但说不清自己当时为什么买 |
| **记得每一个失去的瞬间，记不住任何一条能抄的作业** | 全书 |

### ★ 升级：遗忘不是缺陷，是保护 ★

> **ch131 揭开的第二层**：
> **他记不清第二世小满伤他那段的经过。他一直以为自己是"执念深"。**
> **——不是。他是记不清疼。**

**推论（全书最重要的一条隐藏规则）**：

> **他的记忆在保护他。**
> **因为：记起 → 就会去改 → 改了 → 就得有人挡。**
> **所以世界让他记不住。**

- 卷一-三：读者和他一起以为这是"金手指的副作用"；
- ch114 之后：他开始拼命想记起某些事，**记不起来**；
- ch131：**他明白了——记不起是对的**；
- ch183：**他不再试图记起。这就是释怀的第一个动作。**

> **这一条把"回穿的钥匙是执念"翻了个面**：
> **钥匙不是执念，钥匙是"想起来"。**
> 他这一辈子之所以能继续回来，正是因为**他一直没想起来**。

## 四、脑洞 ④：世界的排异反应 ★★★★☆

> **他改得越多，世界对他越不兼容。**

| 卷 | 反应 |
|---|---|
| 卷一 | ch002：他跟邻居说了那句话，邻居愣了一下——"你这话我好像听过" |
| 卷二 | ch046：一个陌生人跟他打招呼："咱俩是不是见过" |
| 卷三 | ch087：**他开始记错日子。** 他以为周三，其实是周四 |
| 卷四 | ch115：他发现有人（顾延龄）也在改 |
| 卷五 | ch181：**他有时候分不清这一世是哪一世。**<br>——不点破，只给一个细节：他给病人开方子，写错了年份，划掉重写 |

> **纪律**：**永远只给一句话。** 说完就走，下一句照常。
> **这条线的恐怖感全部来自"它从不解释自己"。**

## 五、脑洞 ⑤：他一开局就在别人下过的棋上 ★★★★★

> **已有设定**：顾延龄也在循环，比他早得多。
> **脑洞**：**不要留到 ch107。第一章就埋。**

### 机制

**ch001 他醒来，发现有些事和记忆里不一样——不是他改的，是本来就不同。**

| 例子 | 呈现 |
|---|---|
| 他记得院门口有棵槐树 | **没有。** 他问老妈，老妈说"一直都没有啊" |
| 他记得某个邻居的名字 | 对不上 |
| 他记得老爸第一次发病是在某年冬天 | **提前了** |

### 三条纪律

| # | 纪律 |
|---|---|
| 1 | **第一卷只给三处**，每处一行，他当时没在意 |
| 2 | **他不追查。** 他只是"记错了吧"，然后走开 |
| 3 | **ch107 顾延龄出现时，读者自己把这些串起来** |

> **效果**：**读者在第一章就知道这世界不对劲，但要到 ch107 才知道不对在哪。**
> **而主角到 ch131 才知道——他从来不是唯一的玩家。**

## 六、脑洞 ⑥：他在等一个已经发生过的后果 ★★★★★

> **他的记忆和现实时间错位。他不是预言，他是——在等判决。**

### 机制

**他有时候会突然看日历，然后那一整天不出门。**

| 章 | 呈现 |
|---|---|
| ch010 | 他十二岁那年，突然问老妈"今天几号"。然后一整天没出门。读者不知道为什么 |
| （同一周） | 三天后，院里出了件事（一件小事）。**他早知道** |
| ch038 | 他盯着日历看了很久，然后做了一件事（一件看起来毫无关系的事） |
| ch088 | **他第一次算错。** 不是算错数字，是**他等的后果没来** |

### 为什么这条强

> **"预知"是爽点，"等判决"不是。**
> **他这辈子不是在改变未来，他是在等一个他已经知道的坏消息什么时候到。**
>
> **ch088 那一次，坏消息没来。**
> **——他第一次不知道该高兴还是该害怕。**

> **纪律**：**全书不许写他"看到未来"。** 只写他"记得"。
> **"看到"是超能力，"记得"是一个人的病。**

## 七、脑洞 ⑦：卷首结果页（预叙）★★★★☆

> **每一卷的第一页，先给一个"几年后"的片段。只给结果，不给过程。**

| 卷 | 卷首结果页（≤150 字） |
|---|---|
| 卷一 | **不用**（倒叙钩子已经给了） |
| 卷二 | `三年后，他站在证券营业部门口。兜里三十七块。里面的人在喊，他没进去。` |
| 卷三 | `他看着那个人的背影。没追。（不说是谁）` |
| 卷四 | `他在一张纸上签了字。签完，把笔放回原处。（不说那是什么、死的是谁）` |
| 卷五 | `诊所门口挂着一块牌子。上面没有字。` |

> **纪律**：**结果页不许有情绪词、不许有人名、不许有时间，只能有动作和物。**
> **它是给读者的一个承诺：你读完这一卷就会明白。**

## 八、脑洞 ⑧：章末钩型升级——"不该出现的东西" ★★★★★

> **旧章末钩**：发生了坏事。**——这是最低级的钩子，读者早就免疫了。**
> **新章末钩**：**一个不该出现的东西出现了。**

### 六种钩型（全书轮换，不许连续两章同型）

| # | 钩型 | 例 |
|---|---|---|
| 1 | **凭空多出来的东西** | 抽屉里一张票根，日期是他没去过的那天 |
| 2 | **凭空少掉的东西** | 那张合影上，本该有人的位置是空的 |
| 3 | **不该认识他的人认识他** | 一个陌生人跟他打招呼，叫对他的小名 |
| 4 | **记忆对不上** | 他记得那天什么都没发生，所有人都记得发生了 |
| 5 | **一句无人回答的话** | 他问了一句，没人接。下一章也不解释 |
| 6 | **一个日期** | 章末只有一个日期，没有别的内容 |

> **第 6 型全书最多用三次**（ch073 / ch113 / ch183），**每次都要让人心里一沉。**

### 三条纪律

| # | 纪律 |
|---|---|
| 1 | **章末末句必须是名词或动作**（语言纪律第五节），**不许是情绪** |
| 2 | **钩不许在下一章开头立刻解释。** 最短隔半章，长的隔 50 章 |
| 3 | **每三章至少有一次"无钩"（正常结束）。** 全是钩 = 没有钩 |

## 九、脑洞 ⑨：问题形态的三级升级 ★★★★☆

> **同一个动词"救"，全书问三种不问的问题。读者的脑子必须一直有新东西。**

| 卷 | 问题 | 性质 | 读者的体验 |
|---|---|---|---|
| 卷一-二 | **能不能救** | 能力问题 | 爽 |
| 卷三-四 | **该不该救** | 伦理问题 | 重 |
| 卷五 | **救了算谁的** | 归属问题 | 痛 |

> **每卷换一种问法，是"同一个故事讲 200 章还不腻"的唯一技术保障。**
> **不是加大剂量，是换问题。**

### 配套：每卷的"玩法"也要换

| 卷 | 玩法 |
|---|---|
| 卷一 | **降维**（大人的事，小孩办到了） |
| 卷二 | **预知**（只有他知道） |
| 卷三 | **博弈**（出现一个也不笨的人） |
| 卷四 | **代价**（发现赢是要付账的） |
| 卷五 | **放手**（发现不救才是答案的一部分） |

## 十、脑洞 ⑩：开篇悬念倒置（装在 ch001 前 200 字）★★★★★

> **这是本文件最重要的一条。它决定读者点不点开第二章。**

### 旧钩子（v5）

> 他四十七岁那年……说了半句，她打断了他……那是他这辈子最后一次开口。

**问题**：它很强，但它是**"遗憾"**，而遗憾是被动的——读者只会心疼，不会追。

### 新钩子（v9 升级：加第二段）

```
他四十七岁那年，在城南一家早点铺里，一个女人给他端了碗面。

面很烫。

他跟她说了一句话。说了半句，她打断了他。

"趁热。"她说。

那是他这辈子最后一次开口。

——

他后悔了很久。

不是后悔那半句话。

是更早的那天。那天有人跟他说过一句话，他没听完。

他这辈子都想不起来，那句话是什么。
```

```
风扇在头顶转。粉笔灰在光里飘。讲台上有人点名。

"沈亦舟。"

"到。"

他低头看自己的手。九岁的手。
```

### 为什么这一加，全书都不一样了

| 设计 | 作用 |
|---|---|
| **不知道的遗憾** | 遗憾可以放下，**不知道自己错过了什么，放不下** |
| **"有人跟他说过一句话"** | 读者立刻开始找：**是哪一句？** 全书每一个人说话，读者都在听 |
| **"他没听完"** | 与主题咬死：**他这辈子没听完过任何一个人说话** |
| **"想不起来"** | 与脑洞③（失忆症）咬合——**连后悔的内容都被拿走了** |
| **答案是 ch088** | 小满那句"修车那个人挺好的……你在他那儿坐着，不累"。<br>**读者可能比他先想起来。** |

> **读者和主角一起找一句话，而主角根本不知道自己在找。**
> **——这是全书最长的一根线，也是最便宜的一根：它只需要 60 个字。**

### 六条硬纪律（在 v5 基础上追加两条）

7. **第二段不许超过 60 字。**
8. **"那句话"在 ch088 出现时，不许有任何标记。** 不加引号、不换行强调、不回头提。
   → **ch183 那碗面之后，读者自己想起来。那才算数。**

## 十一、验收（每卷末跑一遍）

- [ ] 本卷的"账"记了几笔？读者有没有可能在 ch087 前自己发现配比？
- [ ] 她有没有入镜？（应该一次都没有）
- [ ] 有没有写"他看到未来"？（应该一次都没有，只能是"记得"）
- [ ] 卷首结果页给了吗？给多了还是给少了？
- [ ] 章末钩型有没有连续两章同型？
- [ ] 本卷问的是"能不能 / 该不该 / 算谁的"里的哪一个？有没有串味？
- [ ] **读者比主角多知道的那件事，本卷是不是还是那件？（"他后悔的是什么"）**
