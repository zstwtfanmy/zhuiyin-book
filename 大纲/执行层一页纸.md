## 一、写之前记住三句话

1. **他不是一个重生者。他是一个记得太多的人。**
2. **他什么都能改，就是改不动别人的选择。**
3. **他不搞笑。他说真话，只是没人信——因为说真话的是个九岁小孩。**

## 二、每章五步（照做就行）

| 步 | 动作 |
|---|---|
| 1 | 打开 `卷纲_第X卷.md`，找到本章那一行的**核心事件** |
| 2 | 想清楚这一章**谁赢了、谁看着**（打脸必须有围观者） |
| 3 | 写。**先写完，不管好坏。** 卡住就写动作，别写心理 |
| 4 | 最后一句改成**名词或动作**（不是情绪、不是省略号） |
| 5 | 如果他这章赢了——**加一句他看老爸的脸色** |

**完事了。** 剩下的二改再对表。

## 三、七条硬禁令（违反任何一条，这一章要重写）

| # | 禁令 |
|---|---|
| 1 | **不许出现**：重生 / 穿越 / 前世 / 系统 / 金手指（连想都不许想，文中一次都不许出现） |
| 2 | **不许写心理活动。** 写动作、写物、写他说了什么。**不写他在想什么** |
| 3 | **不许写拥抱。** 最亲密的表达永远是**递东西**（通常是一杯水） |
| 4 | **章尾末句必须是名词或动作。** 不许情绪，不许省略号 |
| 5 | **主角不搞笑。** 他只是认真地说真话。笑的是别人 |
| 6 | **不许网络流行语。** 他会活到 2030 年 |
| 7 | **不许笑老实人、穷人、他家人。** 可以笑势利眼、骗子、官僚、装腔作势的人 |

## 四、场景速查（写到哪儿查哪儿）

### 打脸 / 爽点

- **必须有围观者。** 没人看着，赢了不算赢
- **他说的每句话都要土。** 越土，被证明对了的时候越爽
- **赢了之后不张扬。** 说完就走，把书包往上提一下
- **赢了之后必看老爸脸色**（卷一）

### 对话

- **俗。** 客套、套话、陈词滥调，全都可以，而且要故意用最没信息量的那种
- **短。** 他说话极短，从不解释
- **他几乎不问问题**（他"知道"，这是他的病）
- **每个人接话的方式固定不变**（王浩＝"真的假的"／老妈＝"**吃不吃西瓜**"／陈默＝慢半拍／舅舅＝"你少来这套"）
  - ⚑ 2026-09-10 修正：老妈的 tic 原文误记为"吃饭了没"（与复沓锚句②撞车）。以 `喜剧层设计·角色回收表` 为准，老妈＝**"吃不吃西瓜"**，ch194 老爸临终那天她没问。
    **"吃饭了没"是别人对他说**的那条复沓线（ch002 小满妈／ch057／ch183），只有 ch001 老妈劝舅舅那一次是例外（一次性，见 `追踪/复沓锚句.md`）

### 情感

- **不写"难过""心痛""百感交集"。**
- **写物**：没喝完的水、凉了的面、空着的座位、多出来的那双筷子
- **失去之后的下一场，必写吃的**（偏执点 A）
- **他听不懂别人的话。** 全书他没听完过任何一个人说话——这是他的病，不是他的错

### 章尾

- 名词或动作。`他把杯子洗干净，倒扣在沥水架上。`
- **每三章至少有一次"不钩"**（正常结束）。全是钩＝没有钩

## 五、卡住了怎么办（按序试）

| 卡在哪 | 怎么办 |
|---|---|
| 不知道写什么 | 打开卷纲，照着那一行的**核心事件**硬写。**细纲没有就自己编，写完再补** |
| 细纲去哪儿找 | **三级**：A 级（全字段·24 章关键章）/ B 级（简版·其余）/ C 级（卷纲一行）。<br>卷一 ch001-026 **已全部就绪**。B 级模板见 `大纲/细纲分级与模板.md` 第三节 |
| 觉得不爽 | 加**围观者**。旁观者反应比主角反应重要 |
| 觉得不疼 | 删掉所有形容词，只留物和动作。**疼是从省略里来的** |
| 觉得不像 2000 年 | 加一个物：搪瓷缸 / 网兜里的黄瓜 / 二八自行车 / 掉角的春联 / 暖壶 |
| 想要解释设定 | **不解释。** 写完就走。读者看不懂是他的问题，不是你漏了 |
| 担心违反纪律 | **不管。继续写。** 第一稿的唯一任务是"存在" |
