# 亲密关系谱系（v6）

> **本文件的定位**：全书六条女性线的**契约层**。
> 与 `情感链条.md` 是互补关系——情感链条管"心"，本文件管"身"。
> **两条线成反比，这是全书最重要的一个结构。**

> **v6 作者裁决（2026-09-08）**：
> ① 结局仍是**独身**；② 但与女性角色的关系**不是纯精神恋爱，要有实质**；
> ③ 爽点打法参考《隐杀》（愤怒的香蕉）。

---

## 一、核心设计：反比原理 ★

> **身体的亲密度，与心的亲密度，成反比。**

| 对象 | 身体 | 心 | 关系时长 | 谁结束的 |
|---|:---:|:---:|---|---|
| 岑玫 | ●●●●● | ○ | 最长的一段（最没有内容） | **她**（问出那句话之后） |
| 温若 | ●●●●○ | ●●●○○ | **唯一长期、唯一同居** | **她**（"别送"） |
| 池遥 | ●●●○○ | ●○○○○ | 短 | **她**（没打招呼） |
| 周晚 | ●●○○○ | ●●●●○ | 一夜 + 一段 | **她**（走得最干脆） |
| 乔蔓 | ●○○○○ | ●●○○○ | 最短（他的第一次） | **她**（"我不想当第一个"） |
| **陈小满** | **○** | **●●●●●●** | **一辈子** | **她**（从来没开始过） |

**两条曲线，方向完全相反。**

> **他睡过的人越多，离那个睡不到的人越远。**
> 每一次亲密都是一次失败的替代行为，而且他**自己不知道**。

## 二、为什么"陈小满是唯一一个没有的"（全书最狠的一笔）★★★

> 这不是巧合，是**机制**。

### 已有规则回顾（v4 定案）

> **说破 = 永别。**
> 他一辈子不说话，是为了还能偶尔见她。

### 推论

**身体关系是最彻底的一种"说破"**——比语言更彻底，因为它不需要主语。

- 他可以和别人上床，因为**那些人不会让他面对那个答案**；
- 唯独和小满不行。**一旦跨过那条线，他就必须承认她选的是别人，**
  **而一旦承认，他就再也见不到她了。**
- **所以他和谁都可以，唯独和她不行。**

> **他不是不敢碰她。他是舍不得失去"还能去她铺子里坐一会儿"这件事。**
> **他用一辈子的克制，换一碗面。**

### 唯一一次机会（ch134，卷四）

| 拍 | 内容 |
|---|---|
| 1 | 她铺子里。雨。没什么人。她递毛巾给他 |
| 2 | 他站起来，往前走了半步 |
| 3 | **他停住了。** |
| 4 | 他说的是："雨小了，我走了。" |
| 5 | 她说："嗯。" |

**纪律**：
① 不写他的心理活动；② **不写她有没有失望**；
③ **这一笔在 ch183 那碗面里回来，不许由任何人提起。**

> **全书他唯一一次主动走向一个女人（ch160，最后一试）——也是为了她，**
> **而那一次他不是去碰她，是去说那句话。**
> **他这辈子对她的所有冲动，最后都只落成一句话。而那句话也没说成。**

## 三、六条线详表

### ① 乔蔓 · 他的第一次（卷二末 → 卷三）

| 项 | 内容 |
|---|---|
| **她是谁** | 卫校毕业，分到药店/后来的社区医院。比他大三岁 |
| **第一次出现** | **ch062**（卷二末）——他生病，她照顾。**她退了**（他那时还小，且她看出来他心里有人） |
| **关系发生** | **ch074**（他 18） |
| **她要什么** | 一个正常的人、正常的日子 |
| **她怎么走** | **ch080**。她说：**"我不想当第一个。"** |
| **签名动作** | 走之前把他衣柜里自己的东西全清空了，**一件没留** |
| **留给他的** | **"第一个"这三个字**——他后来才明白她不是要名分，是要"最后一个" |

> **这一笔的疼点**：她是他第一个女人，也是第一个看穿他的人。
> **她判断的时机比他早了整整一辈子。**

### ② 池遥 · 最轻松的那一个（卷三 ch082-090）

| 项 | 内容 |
|---|---|
| **她是谁** | 圈子边缘的人，自己有事业，不需要他任何东西 |
| **她的台词** | **"我不要你负责。你也别对我负责。"** |
| **性质** | 全书**唯一一段没有重量的关系**——而"没有重量"正是它的意义 |
| **她怎么走** | **ch090 之后自然消失，没打招呼，没交代** |
| **签名动作** | 她从来不留东西在他那儿。**连一个发卡都没有** |
| **功能** | **证明他跟别人是可以轻松的** —— 反衬出他跟小满为什么不行 |

#### ★ ch088：全书最狠的一次并列 ★

> **同一章，两件事，中间隔三页。**

| 顺序 | 内容 |
|---|---|
| 前 | **小满说**："修车那个人挺好的……你在他那儿坐着，不累。"（丁类第二次，她说出答案） |
| 中 | **他没接话。他在忙。** |
| 后 | **当晚他和池遥在一起。** |

**纪律**：
① **不写任何评论、不写对比、不写他的心理活动**；
② 两件事之间**不许有过渡句**——硬切；
③ **这一章不许点题。** 让读的人自己想起来。
④ 这一章**必须单独写细纲**，是全书最难写的一章。

> **这一章一句话版本**：
> **他错过了唯一的答案，然后躺在别人身边。**

### ③ 周晚 · 一夜 + 一段（卷三 ch090 / ch096-098）

| 项 | 内容 |
|---|---|
| **她是谁** | 第一世金融时期的同行。**唯一一个看得懂他每一步的人** |
| **本世重逢** | ch089 |
| **关系发生** | **ch090** —— 两个人都知道没有明天 |
| **性质** | **势均力敌**。她不是被他征服的，是**她选的一次** |
| **她怎么走** | **ch096-098**。方式不同，**日期和第一世一模一样** |
| **签名动作** | 走之前把他书架上一本他没看过的书抽走了，**没说** |
| **留给他的** | `"原来不是我没说，是我说了也没用。"` |

> **三级递进·第一级「时机」**：这条线的痛点是"重来救不了犹豫"。
> **而 ch090 那一夜，正是他以为自己已经不犹豫了的时候。**

### ④ 温若 · 最深最久、唯一同居（ch103 → ch180）

> **这条线是六条里唯一的重头戏，详见 `情感链条.md` 第八节。本文件只补身体维度。**

#### ★ ch103：他用身体回答了一个不敢用语言回答的问题 ★

| 拍 | 内容 |
|---|---|
| 前 | **ch100-101**：她说了半句，被小满的事打断。他把后半句留在了房间里 |
| 中 | **ch103**：他没有说话。他走过去 |
| 后 | **第二天早上，他起来，倒了一杯水放在她那边，出去了** |

**纪律**：
① **不写"他为什么"** —— 他自己也不知道；
② **不写她哭**；
③ **她看着那杯水，就知道了** —— 这一句**不写出来**，靠下一个动作暗示（她把水喝了，然后自己也起来了）。

> **这一笔的力量**：
> **他不是不爱她。他是除了这个，什么都说不出来。**
> 而她接受了，因为她知道**这是他能给的全部**。

#### 她最终怎么走（ch180）

- **她说"别送"。他没去。**
- **她走的原因不是没得到他，是"得到了人，得不到心"。**
- 她这辈子跟他住了十几年，**她知道他半夜醒来是去想谁的。**

> **独身结局的新解释（v6）**：
> 他不是"没人要"，也不是"忘不了她"。
> **他是一直在别人身上找她的影子，找到了身体，找不到人。**
> **最后他不再找了。这就是释怀。**

### ⑤ 岑玫 · 点破他的那一个（卷四 ch126-140）

| 项 | 内容 |
|---|---|
| **她是谁** | 圈子里的人。聪明、体面、**不缺人追** |
| **性质** | 六条里**身体最多、心为零**的一段。**他自己也开始滥了的时期** |
| **转折** | **ch138**。她问：**"你到底在找谁？"** |
| **他的反应** | **答不上来。**（全书他答不上来的问题只有两个，这是第一个） |
| **结束** | **当天。** 她自己走的。**她走得很轻，甚至有点高兴** |
| **签名动作** | 她走的时候把门带上了。**全书唯一一次有人给他关门是轻的** |

> **为什么必须有她**：
> 前面四条线，都是她们自己想明白了。
> **这条不一样——是她把他的病说出来了，而且是从一个最不重要的人口里说出来的。**
> **越不重要的人，说出来的真话越狠。**
> 这一问直接把读者推向 ch115-125 的论道。

> 见第二节。**她给了他一碗面。这是全书唯一一次有人给他东西。**

## 四、「一杯水」复沓（v6 新增资产）★★

> **他这辈子表达亲密，只会一个动作：倒一杯水，放在对方那边。**

| 章 | 场景 | 变体 |
|---|---|---|
| **ch003** | 给老爸倒的第一杯水（F1 起点） | 父子 |
| ch074 | 乔蔓之后 | 第一次用在女人身上 |
| ch084 | 池遥之后 | — |
| ch090 | 周晚之后 | — |
| **ch103** | **温若之后 · 第二天早上** | **这一杯是全书的分水岭：她喝了，然后自己也起来了** |
| ch134 | 小满铺子里，雨。**她倒给他的是茶** | **唯一一次是别人倒给他（除了最后一碗面）** |
| ch138 | 岑玫之后。**他倒了，她没喝** | **她没喝 = 她已经想明白了** |
| **ch183** | **她端来一碗面。"趁热。"** | **他终于喝到了别人给的东西** |
| **ch194** | 老爸临终："我这辈子最享的福，就是你给我倒的那杯水。" | **回收 F1** |

**纪律**：
1. **每次只写动作，不写意义。** 读者自己会串。
2. **他自己的那杯，从来不喝。**（全书不写他喝水的样子，除了最后一碗面）
3. **岑玫那一杯必须没喝**——六次里唯一一次被拒绝，且拒绝得轻描淡写。

> **一句话**：**他这辈子只会倒水，也只倒过水。而唯一一个给他端过东西的人，是他从没碰过的那个。**

## 五、尺度与笔法（v7 · 见 `作者性/亲密场景笔法.md`）★

> **v6 的「八条硬纪律」已作废，原因见下。笔法全在 `作者性/亲密场景笔法.md`，本节只记要点。**

### 为什么改

v6 定的"只给三个镜头、不写过程"是**文学向的省笔**。
干净是干净，代价是：**爽感没了，人物扁平了，六条线读起来都一样**——**太含蓄，也没意思。**

> **参考《隐杀》的真实尺度**：起点 208 万字完整上架，书评原话是
> "邪恶的大魔王本质暴露无遗""YY 的水准令人叹为观止""思想邪恶的人请进来"，
> 但同时"情感真挚炽烈""俗套桥段在细腻笔触下闪出不一般的魅力"。
> **它不露是技巧，不是尺度。它的密度、感官、余韵，全都写足了。**

### 定档：乙档

**写到"进去了"为止，用一句带过；之后全力写余韵。**
**把 90% 的字数花在"进去之前"的张力和"出来之后"的余韵上。**

### 五条要点（详见笔法文件）

| # | 要点 |
|---|---|
| **1** | **分镜慢写**（与打斗、望诊同一套）：一个动作拆 5-8 拍，**声音永远最后到** |
| **2** | **感官优先级：气味 > 温度 > 触感 > 声音 > 视觉。** 视觉克制，触觉嗅觉大方 |
| **3** | **心理的「半秒」**：写停顿/走神/犹豫，**不写想法**（"三不写"的唯一合法变体） |
| **4** | **事后台词**：隐杀的灵魂。每条线至少一句，且必须符合该人对话签名 |
| **5** | **★ 日常里的身体感**：每卷 ≥3 处，不许只在床上出现 |

### ★ 两条本书独有的（比隐杀更狠）

| # | 内容 |
|---|---|
| **一** | **他在床上无所不能，在感情上一句话都说不出来。**<br>他的手能摸出三十种脉象，**摸不出一个人要不要留下**。<br>→ **他的全部能力都在身体上，而这本书的主题恰恰是"身体解决不了的事"** |
| **二** | **镜头落在"手"上。** 他的手：药碾子的茧、很稳、很凉、**碰人之前先停半秒**。<br>六个人六种手；**温若的手跟他一样（药渍）——她用了十几年，把自己活成了他的样子** |

### 六条线六种质感（不许写成同一场戏的复刻）

| 线 | 质感 | 篇幅 |
|---|---|---|
| 乔蔓 | **生**（生涩、快、他起身就走） | 800-1200 字 |
| 池遥 | **轻**（顺、不留东西） | 600-900 字 ×2-3 |
| 周晚 | **急 + 清醒**（她一直在看他） | 1000-1500 字 |
| 温若 | **熟**（长期默契，唯一事后一句话都没有的） | **1200-1800 字（最长）** |
| 岑玫 | **多而空**（写得越多越要写"空"） | 600-1000 字 ×多次 |
| 小满 | **空**（0 字，但 ch134 要有 300 字的"差一点"） | 300 字 |

> **总配额约 5000-7000 字 ≈ 全书 1%。够密，不抢主线。**

### 保留的三条（v6 里没动）

1. **不许写拥抱**（偏执点 B）—— **他睡过很多人，他这辈子没有抱过任何一个人。**
2. **事后必有一件"递东西"的动作**（通常是那杯水）。
3. **前后 5000 字内不许出现"爱"字。**
4. **前 60 章一条都不出现**；简介与开篇三章绝不暴露。

## 七、风险与缓解

### R·渣男观感（★★★★☆）

**风险**：男主睡了 5 个女人最后独身，容易被读成"渣"。

**三条缓解（缺一不可）**：

| # | 缓解 | 说明 |
|---|---|---|
| 1 | **人数 ≤5，且任何一条都不超过一段正式关系** | 不写"后宫"，写"履历" |
| 2 | **五个全部是她们先走，且都想明白了才走** | 他这辈子没甩过人，也**没留住过任何人** |
| 3 | **他不主动、不承诺、不撒谎**（H3 + 纪律 7） | **他从头到尾没骗过任何一个人** |

> **第 2 条是本书的护身符**：
> **她们走，不是因为被辜负，是因为她们各自有主线。**
> **这恰好是全书主题本身。**

### R·与"细腻"冲突（★★★☆☆）

**风险**：写了身体，情感浓度反而被稀释。

**缓解**：**身体戏越多，情感戏越静。**
每一次亲密之后，下一场必须是**静的、物的、无对话的**。
→ **纪律：亲密场景的下一场，必定出现"吃的"或"水"（偏执点 A + 一杯水复沓）。**

### R·爽文读者接受度（★★★☆☆）

**缓解**：**前 60 章不出现任何一条。** 先让读者吃够爽，再让人物复杂化。
且**简介与开篇三章绝不暴露这条线**。

## 八、为什么这些线反而加固了主题 ★★★

> **"他改得了天下人的命，改不了一个人在不被胁迫时凭自己心意做出的选择。"**

**六条女性线 = 这条规则的六次演示，六种不同的选择：**

| 对象 | 她的自愿选择 | 他听懂了吗 |
|---|---|---|
| 乔蔓 | **"我要当最后一个，不是第一个"** | 没有 |
| 池遥 | **"我不要名分"** | 没有（他甚至没发现她走了） |
| 周晚 | **"我要走"**（日期都不变） | 他以为是自己没开口 |
| 温若 | **"别送"** | **这一次他听懂了**（唯一一次） |
| 岑玫 | **"不要一个心里有人的"** | **答不上来** |
| **小满** | **"郑川"** | **到死（ch183）才明白那不叫辜负** |

> **他用了六段关系，才学会一件事：**
> **别人的选择不是冲着他来的，那只是她们的日子。**

**所以"独身"不是惩罚，是结果**：
**他不是没人爱，他是一直在别人的日子里找自己的位置，最后不找了。**
