# 语体样张（ch001 · 落笔的样子）v9

> **为什么写这个**：第八轮评估里**语言质感 8.8 是七维最低的一项**。
> 但它低不是因为规则不够——**规则已经有五十条了**。低的原因是没有一个"落笔时的样子"可以对照。
>
> **本文件是全工程唯一一份"示范文字"。**
> 它的作用不是当正文用，是**给执行层一个音高**——写之前读一遍，写完对着改一遍。
>
> **定稿纪律**：本样张由编排层写，**写正文时可以直接照这个音高走，不必逐句照抄**。

---

## 一、样张正文（约 1400 字）

### 倒叙钩子（定稿，照抄，不许发挥）

他四十七岁那年，在城南一家早点铺里，一个女人给他端了碗面。

面很烫。

他跟她说了一句话。说了半句，她打断了他。

"趁热。"她说。

那是他这辈子最后一次开口。

——

他后悔了很久。

不是后悔那半句话。

是更早的那天。那天有人跟他说过一句话，他没听完。

他这辈子都想不起来，那句话是什么。

——

### 正文

风扇在头顶转。粉笔灰在光里飘。

讲台上有人点名。

"沈亦舟。"

"到。"

他低头看自己的手。九岁的手，指甲剪得太短，食指侧面有一道铅笔压出来的印子。

他看了很久。

"沈亦舟。"

"到。"

同桌用胳膊肘碰他。他抬头。讲台上的人已经念到下一个名字了。

——

放学的时候太阳还很高。

院门口蹲着几个下班的男人，自行车支在墙根，车把上挂着网兜，网兜里是黄瓜和一块豆腐。

李婶家的孩子在台阶上坐着，三四岁，脑门上贴着一块退热贴，歪着。

他走过去的时候多看了两秒。

孩子没什么精神，眼睛半睁着，手在半空中抓了一下，没抓着什么。手指头是直的，不太会弯。

他说："他不是要睡觉。"

李婶抬头："什么？"

"他是要抽。"

李婶笑了，伸手把孩子揽过去，用下巴蹭了蹭孩子的头顶。

"你这孩子，哪儿学的这些词儿。"

王浩在旁边推了他一把："真的假的？"

他没答。

"你别吓人家。"李婶说，"就是白天玩疯了，困的。"

他站了一会儿。

"晚上别让他睡沉了。"他说。

"行行行。"

李婶抱着孩子站起来，进屋了。门在身后关上，门框上的春联掉了一个角，在风里翻。

王浩还在旁边："你真会啊？"

"不会。"

"那你说的什么。"

"我看的。"

"看哪儿？"

他没说话。书包带子勒着肩膀，他往上提了一下。

——

那天夜里十一点多，院子里炸了。

李婶家的人在楼道里喊，喊的是孩子的小名。紧接着是拖鞋踩楼梯的声音，一声接一声，往下跑。

他家的灯也亮了。他妈披着衣服出去看，回来的时候脸还是白的。

"抽了。"她说，"嘴都紫了。"

他坐在床沿穿衣服。

"你穿衣服干什么。"

"去看看。"

"看什么看，睡觉。"

他妈说完又出去了。

——

第二天早上，李婶回来了。

她在院门口站着，跟两三个女人说医院的事，说抢救室的灯，说护士跑进跑出。

说到一半她停下来，转过头。

"沈家那孩子呢？"

"上学去了吧。"

"他昨天跟我说什么来着？"

"说什么？"

"他说——"李婶想了想，"他说，晚上别让他睡沉了。"

几个女人都不说话了。

过了一会儿有人说："医生也是这么说的。"

"医生说，再让他睡沉一点，就抽在里头了。"

"一个九岁的。"

"可不是。"

——

他放学回来的时候，院门口多了几个人。

都站着，像是在等谁。看见他，有人喊了一声："舟舟，过来。"

他把书包换了个肩。

"你咋知道的呢？"李婶问。他看见她手里攥着一个苹果，塞给他。

他没接。

"看的。"他说。

"看哪儿？"

"看手。"

"手怎么了。"

"手指头直着，不会弯。"

李婶愣住了。

他把书包往上提了提，说："我作业还没写。"

——

他走到自家门口的时候，听见屋里有人说话。

声音不小。是舅舅。

"……不是我说你，建国，你这辈子也就这样了。"

他站在门口，没推门。

"三十八，四十了？厂子没了，手艺没有，你拿什么养这一家子。"

屋里没人接。

过了会儿老妈说："哥，吃饭了没，我给你盛。"

"不吃。"舅舅说，"我说的是实话。你这人就是不爱听实话。"

还是没人接。

他推门进去。

堂屋里光线暗，老爸坐在里屋门口的小板凳上，背对着外头，手放在膝盖上。

舅舅坐在八仙桌那边，看见他，话头一转："舟舟回来了。"

"舅舅。"

他把书包放在椅子上，进了厨房。

老妈在切黄瓜。刀在案板上，一下，一下。

"回来了？"

"嗯。"

"洗手。"

他洗了手，出来的时候，从暖壶里倒了一杯水。

他端着走进里屋，放在老爸手边的小桌上。

放的时候，他把杯把手转了一下，朝外。

老爸看了他一眼。

"喝点水。"他说。

老爸"嗯"了一声。

他转过身出去。走到门口的时候他停了一下，回头看了老爸一眼。

脸色不对。眼白有点黄。手放在膝盖上，指头是抖的，抖得很轻，不仔细看看不出来。

他什么都没说，出去了。

堂屋里舅舅已经站起来了，在穿外套。

"我走了啊。"

老妈送到门口。

院子里，天还没黑透。有人在开水龙头，水声哗哗的。

他把杯子洗干净，倒扣在沥水架上。

## 二、逐处技法批注

| 位置 | 技法 | 为什么 |
|---|---|---|
| "他低头看自己的手。九岁的手" | **镜头落在手上**（语言纪律第三节） | 全书所有场景第一笔默认落手 |
| "指甲剪得太短，食指侧面有一道铅笔压出来的印子" | **名词堆叠，不解释**（双雪涛） | 不写"他看着自己的手，心中百感交集" |
| "到。" ×2 | **重复**（招②变奏） | 第二次他没听见，读者立刻知道他不对劲 |
| "网兜里是黄瓜和一块豆腐" | **年代质感，靠物不靠说明** | 不写"那是 2000 年" |
| "手指头是直的，不太会弯" | **望诊：只写看见的** | 不写"他一眼看出是高热惊厥" |
| "他是要抽" | **土话，不许高明** | 医生后来说的是同一个意思——**这就是"一字不差"** |
| "你这孩子，哪儿学的这些词儿" | **笑点在别人，不在他** | 主角自己不搞笑（纪律第 2 条） |
| "真的假的？" | **王浩的接梗方式**（固定不变） | 喜剧层招⑥：班底接梗 |
| "你别吓人家" | **俗套对话** | 俗在对话，雅在叙述 |
| "门框上的春联掉了一个角" | **闲笔**（每 3 章一次手艺细节） | 不服务情节，只服务味道 |
| "看手。""手怎么了。""手指头直着" | **对话极短，不解释** | 他说完就走，不炫技 |
| "可不是" | **最俗的一句话收场** | 围观者的反应，用废话写 |
| "他把书包换了个肩" | **动作代替情绪** | 他不知道怎么应对大人的热情——**不写他尴尬** |
| 隔门听见 | **羞辱是背地里的** | 比当面更狠，也更真实 |
| "哥，吃饭了没，我给你盛" | **老妈永远不在点上**（接梗方式） | 喜剧层招⑥ |
| "屋里没人接" ×2 | **沉默写两遍** | 老爸的处境：被羞辱但不吭声 |
| "他把杯把手转了一下，朝外" | **F1 第一次出现** | 不加任何说明，ch194 才回收 |
| "喝点水。" | **他唯一的亲密语言** | 全书他只会倒水 |
| 眼白有点黄／指头是抖的 | **望诊老爸，不点破** | 只写他多看了两眼 |
| "他把杯子洗干净，倒扣在沥水架上" | **章尾是动作** | 不是情绪，不是悬念——**第一章的钩子已经在前 260 字给了，结尾可以松** |

### 这一章的笑点（3 个，符合卷一配额 3-5）

1. 李婶"你这孩子，哪儿学的这些词儿" —— **他说的每一句都是真的，但没人信，因为他是九岁**
2. 王浩"真的假的？""看哪儿？" —— 班底接梗
3. 老妈"哥，吃饭了没" —— 永远不在点上

> **注意这三个笑点没有一个是主角制造的。**
> **主角从头到尾是认真的，而且是对的。**

## 三、三条反例（写错的样子）

> **这三条比正面示范更重要。** 每一条都是这本书最容易掉进去的坑。

### 反例 1：把"克制"写成"空白"

❌ 他看着自己的手，心中五味杂陈。三世为人，他又一次回到了这里。

- 出现"三世"二字（**全书禁用词**）
- 写心理活动（三不写）
- "五味杂陈"是成语（禁用）

✅ 他低头看自己的手。九岁的手。

### 反例 2：把"专业"写成"炫技"

❌ 他一眼看出那是高热惊厥的前兆——小儿神志尚清，但手足拘急，此乃热极生风之象，若不及时处理……

- 用了术语（**望诊的话必须土**）
- 一句长句解释（**对话签名：他说话极短**）
- 他在向读者展示自己（**主角不炫技**）

✅ "他是要抽。"

### 反例 3：把"喜剧"写成"段子"

❌ 李婶翻了个白眼："你咋不上天呢，九岁就当起大夫了，下一步是不是要给我开个方子啊？"

- 网络流行语（**禁用**）
- 李婶在主动抖机灵（**接梗角色只接，不抖**）
- 笑点朝下（笑的是小孩，但方式变成了嘲讽式的俏皮话，油滑）

✅ "你这孩子，哪儿学的这些词儿。"

> **区别在哪**：反例里李婶在"表演"，正例里李婶只是"没当回事"。
> **生活里的喜剧都是后者。**

## 四、这一章读者读完必须记住的两件事

1. **这孩子有本事**（望诊说中了，医生证明了他）；
2. **这家很穷，而且被人看不起**（舅舅那句话）。

**不许在这一章塞第三件事。**（v9 已把"不存在的槐树"和"第二天的小祸"移到 ch002）
