# 粒度配置（执行层档位）

> 同一框架，按执行层模型分档。框架读本文件组装任务流。
> **v10 定档**：旧版四项全为 `{{}}` 占位，框架无法组装任务流，一律按默认档跑——
> 而本书对**语言质感**要求高（七维 9.2，靠的是分寸不是信息量），默认低档会把"克制"写成"空白"。

## 当前档位（本书定案）

| 项 | 取值 | 理由 |
|----|------|------|
| 执行层模型 | **中档模型（默认）** | 本书的难点在分寸（三不写、章尾是名词或动作、比喻域分层），低模型易写成"合格但平" |
| beat 粒度 | **一次半章**（中档）；按细纲密/疏分组——密 beat 500-2000 / 疏 beat 100-300 / 铺垫 300-800 | 情绪峰值 beat 不拆，保住一口气 |
| 两遍生成范围 | **仅关键 beat（默认开）** | 关键 beat＝每章的多采样外选位（细纲写作指令区已标注） |
| 多采样 | **情绪峰值 beat 抽 3-5 版（默认开）** | 本书的"外选"问的是"哪版更接近气句"，不是"哪版更爽" |

## 本书多采样外选位（默认触发点）

| 类型 | 位置 | 外选问法 |
|---|---|---|
| 打脸台词 | 每次打脸的那一句 | 取"**最像小孩说的**"那版，不取最狠的那版 |
| 望诊/专业判断 | 每次他说出判断的那句 | 取"**最土**"的那版（禁用术语），不取最高明的那版 |
| 亲密场景 | 事后那半句话 | 取"**最不像台词**"的那版 |
| 论道机锋 | ch119-124 每一问 | 取"**最平**"的那版——最狠的话要平着说 |
| 章尾末句 | 每章最后一句 | 必须是名词或动作；取"**最不总结**"的那版 |

> **本书外选的总原则**：问"哪版更像**没当回事**"，不问"哪版更精彩"。
> 气句＝玩世不恭中，总有那么一丝深刻——**前者在表面，后者在底下**。

## 分档参考

| 执行层 | 粒度 | 模式 |
|--------|------|------|
| 强模型（Opus 级） | 一次一章 | 编排层少拆步骤 |
| 中档模型（**本书默认**） | 一次半章 | 中间粒度 |
| 低模型（deepseek-flash 级） | 按细纲密/疏分组（密 500-2000 / 疏 100-300 / 铺垫 300-800） | 全卡片化 + 多采样外选 |

> **降级预案**：若执行层只能跑低模型，切回低档并在卡上**硬写三条禁令**
> （不写心理活动 / 章尾是名词或动作 / 禁用四个词），可保住下限，但语言质感会掉到 8.5 附近。

## Σ 缺口传导规则（X2，ch61 实证倒逼）

切 beat 时若 Σ(情节点预算) < 章字数目标，缺口分配进密 beat 的上限扩展（密 beat 上限 2000 即为承接展开量的容器）——治细纲「需补 N 字」无处可补的断链。章总字数预算与 wordcount 双口径下限不动（总量照管，分布放开）。

> **本书实测**：ch001-005 五章预算合计均在 2800-3600 区间，缺口普遍落在望诊/打脸两个密 beat，
> 属正常——**宁可让"看手"写透，不许给"记忆涌入"加字**（v9 硬纪律：倒叙段照抄样张，不许扩写）。
