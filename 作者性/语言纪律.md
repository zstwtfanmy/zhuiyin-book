# 语言纪律（本书的笔法契约）v5

> **为什么单独立一份**：`指纹.md` 只有四个参数，管不了笔法。
> 本文件是**执行层写每一句话时对照的东西**。写之前读一遍，写完自查一遍。
>
> **定调**：**白描为底（阿城）+ 名词堆叠写情感（双雪涛）+ 机锋对白写思想（豆豆）。**
> 不学骈俪，不学煽情，不学网络吐槽体。

---

## 一、三不写（全书的硬禁令）

| # | 禁 | 反例 | 正例 |
|---|---|---|---|
| 1 | **不写心理活动** | "他心里一沉，忽然明白了什么" | 他把手里的杯子放下，放得很正 |
| 2 | **不写"感到 / 觉得 / 意识到 / 心头一X"** | "她感到一阵失落" | 她把手在围裙上抹了两下 |
| 3 | **不写情绪比喻** | "心像被啃了一口" | （不写。换成一个物） |

> **第 1 条原只约束论道一场，v5 起推广到全书。**
> 唯一的例外：卷末章允许一句气句（见第五节）。

**自查法**：写完一段，搜索"心里""感到""觉得""意识""仿佛""像是"。
命中就改——**改成动作，或改成一个物件。**

## 二、比喻域分层（替换原"三域混用"）★

> **原设定"金融+中医+特种兵三域混用"作废——三域混用等于没有域。**

| 层 | 域 | 用在哪 | 例 |
|---|---|---|---|
| **主域** | **药与病** | 他看世界的方式。诊断、判断、识人 | "这人脸上带滞色，是气不顺，不是累" |
| **副域** | **面与火** | **她看世界的方式。全部情感场景专用** | "面要醒够时辰，急了就发不起来" |
| **器域** | **数与账** | **只在顾延龄线与算账时出现** | "三千换三十，这笔账划算" |
| **禁用域** | 军事 / 武侠 / 游戏 / 体育 / 天气 / 海洋 | — | 一律禁 |

### 三条纪律

1. **一个场景只用一域，不许混。**
2. **情感场景一律用"面与火"，禁用"数与账"。**
   → 这一条是全书语言层的主题实现：
   **他用"药与病"看世界，她用"面与火"看世界。**
   **两个人从头到尾说的不是一种语言——这就是他们不可能的原因。**
3. **器域是"病"**。
   → **凡是主角开始用数字形容一个人的时候，读者就该知道他又错了。**
   → 全书他最后一次用数字，是 ch160 之前。ch160 之后他再没算过账。

## 三、镜头习惯（填实原"不固定"）★

> **场景第一笔一律落在"手"上。**

| 情绪 | 禁写 | 写 |
|---|---|---|
| 累 | 他很累 | 他把手在裤子上擦了擦 |
| 难过 | 她眼眶红了 | 她把手在围裙上抹了两下，抹了三遍 |
| 紧张 | 他心跳加速 | 他把手指节按得发白 |
| 心虚 | 他有些心虚 | 他把手插进兜里，又抽出来 |

> **为什么是"手"**：他是中医（把脉、抓药）；她是做早点的（碱面）；
> 程守拙手抖、抓药用手撮；**"手"是这本书的职业签名。**
> 而且它与偏执点 A（吃的东西必须用"手"递）天然同构。

**纪律**：每场戏**至少一次手部特写**，但**同一场不许出现两次同一只手的同一动作**。

## 四、对话签名（每人一句话的字数上限 + 句式）★

| 角色 | 一句话上限 | 句式 | 备注 |
|---|---|---|---|
| **沈亦舟** | **越认真越短，≤15 字** | 陈述句。**几乎不问问题** | 他"知道"，所以他不问。这是他的病 |
| **陈小满** | **≤10 字，主语常省** | "趁热。""我帮你。""你忙你的。" | 全书不许她长句 |
| **程守拙** | ≤20 字 | **反问句为主，从不给结论** | |
| **顾延龄** | ≤20 字 | **句子里必带数字** | "三千""三十""一比一百" |
| **温若** | **无上限。全书唯一说完整长句的人** | 复句，会替他把话收尾 | **她是把话说出口的人** |
| **郑川** | ≤5 字 | 几乎不说话 | |
| 赵铁柱 | 废话多 | 口头禅"得嘞"，正经话一句没有 | |
| 苏老 | 长句 | 农活比喻（"这病得像拔草"） | |
| 周晚 | 中长句 | 专业词当日常用语（"这个仓位"） | |
| 沈建国 | **≤8 字** | 夸人只会说"还行" | |

### 两条从签名长出来的硬纪律

**① 温若是唯一说完整长句的人。**
> → 她也是唯一把话说出口的人。
> → **所以她是唯一没被听见的人**（ch101 被打断）。
> → **这是主题在句法层的实现，不许破坏。**

**② 问号分布（重要）**

| 谁会问问题 | 谁不问 |
|---|---|
| 程守拙（他在问证）<br>顾延龄（他在算账）<br>姜淮（"你怎么什么都知道"）<br>温若（她问了，他没答） | **沈亦舟几乎不问**——他"知道"<br>**陈小满从不问**——她不问为什么 |

> → **主角不问问题，是他最大的病。**
> → 全书他第一次问出问题，是 ch122（论道第三问被驳后）——
>   而那其实也不算问题，是一句"那我这辈子算什么"。
> → **他到死没学会问。**

## 五、章尾纪律

> **每章最后一句必须是"名词"或"动作"。**
> 不许是情绪句、总结句、悬念句、感慨句。

| 禁 | 可 |
|---|---|
| "他不知道，这一别竟是永别。" | 门在他身后关上了 |
| "命运，从来不会放过任何人。" | 桌上的碗还温着 |
| "他终于明白了一个道理……" | 他把杯把手转向外面 |

**例外**：每卷的**末章**允许一句气句（全书共 5 次，用完即止）。

## 五点五、身体场景（v7 · 亲密关系专用）★

> **完整笔法见 `作者性/亲密场景笔法.md`。本节只记与通用语言纪律的咬合处。**

| # | 纪律 |
|---|---|
| **1** | **定档乙**：写到"进去了"为止一句带过，**90% 字数给"之前"和"之后"**（详见笔法文件第一节） |
| **2** | **分镜慢写 5-8 拍**，与打斗、望诊同一套笔法（H4）。**声音永远最后到** |
| **3** | **感官优先级：气味 > 温度 > 触感 > 声音 > 视觉。** 视觉克制，触觉嗅觉大方 |
| **4** | **比喻域约束**：亲密场景**只用"面与火"副域**（情感专用），禁用"数与账"器域 |
| **5** | **不许写拥抱**（偏执点 B）。**他这辈子没有抱过任何人入睡** |
| **6** | **事后必有一件"递东西"的动作 + 一句台词**（通常是那杯水） |
| **7** | **这类场景前后 5000 字内不许出现"爱"字** |
| **8** | **心理只写「半秒」**：停顿/走神/犹豫，**不写想法**（"三不写"的唯一合法变体） |
| **9** | **每人的气味全书一致，六人六种**；**日常身体感每卷 ≥3 处** |
| **10** | **六条线六种质感**（生/轻/急/熟/多而空/空），不许写成同一场戏的复刻 |

> **与"三不写"的关系**：第 8 条是全书禁心理活动的**唯一例外**——
> **可以写"他的手停了半秒"，不可以写"他想起了她"。**

> **副产品（全书最疼的一句潜台词）**：
> **他睡过很多人。他这辈子没有抱过任何一个人。**
> **这本书从头到尾没有一次拥抱，读者却会觉得它很烫。**

> **本书独有（比隐杀更狠的一处反差）**：
> **他在床上无所不能，在感情上一句话都说不出来。**
> **他的手能摸出三十种脉象，摸不出一个人要不要留下。**

## 六、标点癖好（填实）

1. **对话少叹号**（全书叹号不超过 20 处，且只给赵铁柱和配角）；
2. 停顿用**句号**，不用破折号；
3. **★ 全书对话禁用省略号表示迟疑。**
   迟疑一律写成**动作**："他没接话。" / "她把后半句收回去。"
4. **★ 问号只出现在第四节的"会问的人"嘴里**（主角和小满的台词里，问号应有意识地极少）；
5. 引号内**不许出现心理描写**，只许出现说的话。

## 七、闲笔频率（填实原"不固定"）

> **每 3 章一次，且只写"与主线无关的手艺细节"。**

内容池：**怎么和面 / 怎么炒药 / 怎么认药材 / 怎么包书皮 / 怎么修自行车 / 怎么择菜 / 怎么磨刀**。

**功能**：
1. 手艺细节是**世界可信度的来源**（这本书的专业感全靠它）；
2. 是**节奏的呼吸**（大爽之后给一段闲笔，比直接切下一场高级）；
3. **不许服务情节**——一服务情节就不是闲笔了。

**纪律**：闲笔段 **≤150 字**，且**不许出现在任何情绪峰值的前后两章**。

## 八、句式基准（阿城式动词经济）

> 基准句式：**主语 + 动词，不加副词，不加形容词。**

| 改前 | 改后 |
|---|---|
| 他非常缓慢地转过身来 | 他转过身 |
| 她小心翼翼地把碗端起来 | 她端起碗 |
| 他极其认真地看了看那张方子 | 他看了那张方子 |

**例外**：情绪峰值的那一场允许破例（全书不超过 5 处），
且破例时必须**突然变长**——长短对比才有力量。

## 十、执行层自查清单（每章写完跑一遍）

- [ ] 有没有"心里 / 感到 / 觉得 / 意识到"？ → 改
- [ ] 这一场用了哪几个比喻域？ → 超过一个就删
- [ ] 场景第一笔是不是落在"手"上？ → 不是就改
- [ ] 对话有没有超出角色的字数上限？ → 超了就砍
- [ ] 有没有用省略号表示迟疑？ → 改成动作
- [ ] 章尾最后一句是名词或动作吗？ → 不是就改
- [ ] 偏执点 A（吃的）在本章是否该在场？ → 该在没在就补
- [ ] **偏执点 B（不写拥抱）有没有被违反？** → 有就改
