# 作者指纹（本书掌纹）

> 开书时随机或选定一组，写入每张写作卡的范文段与禁令段。全书一致，书书不同。
> 皮的一部分：换一本书可以整套换掉。
> 默认弹药（比喻域/镜头/闲笔/标点）见 [参考-气质谱系.md](参考-气质谱系.md)——圈用或改写成自己的，装填位置见其对照表。

| 掌纹参数 | 本书取值 | 说明 |
|---------|---------|------|
| 比喻来源域 | **药与病（主域）／面与火（副域·情感专用）／数与账（器域·只给顾延龄线）**<br>**v5 填实**（原"金融+中医+特种兵三域混用"作废——三域混用等于没域）<br>禁用：军事 / 武侠 / 游戏 / 体育 / 天气 / 海洋 | 本书写比喻只从这三池里捞，**一个场景只用一域** |
| 镜头习惯 | **场景第一笔一律落在"手"上**<br>**v5 填实**（原"不固定"作废） | 他是中医（把脉抓药）／她是早点的（碱面）／程守拙手抖撮药。"手"是职业签名 |
| 闲笔频率 | **每 3 章一次，≤150 字，只写手艺细节，不许服务情节**<br>**v5 填实**（原"不固定"作废） | 和面／炒药／认药材／包书皮。世界可信度的来源 + 节奏的呼吸 |
| 标点癖好 | 对话少叹号（全书 ≤20 处，只给配角）；停顿用句号不用破折号；<br>**★ 禁用省略号表示迟疑**（改写成动作）；**★ 问号只给"会问的人"**（程守拙／顾延龄／姜淮／温若） | 主角几乎不问问题——因为他"知道"。这是他的病 |

> **笔法的详细契约见 `作者性/语言纪律.md`**（三不写 / 比喻域分层 / 对话签名 / 章尾纪律 / 自查清单）。
> 本文件只登记参数，细则一律以语言纪律为准。

## 使用规则（编排层）

- 写作卡组装时：比喻域写进禁令段（"比喻只用{{域}}"）；镜头习惯写进感官入口指令；标点癖好写进禁止项；
- 指纹冲突时以本文件为准，覆盖范文切片的同类特征；
- 封神测试用：三本书换三套指纹，读者应能区分"不是同一个作者写的"。
